# 第2ラウンド：理不尽な孫の手の応答（三嶋レビューへ）

三嶋のレビューは第1幕の指摘を含め、ほぼ正しいと思います。ただ「負債の線」を崩す提案が2つあり、そこは守ります。

## 1. 譲れないもの(最大6)
1. **F1 待て/よし→待て破り(ep2・3 → ep20・21)**
   捨てると、最終行「待ては、できませんでした」が愛の爆発に落ち、背骨が消えます。
2. **手負い残し→白石の死→全滅戦(F2。ep0 → ep12 → ep13)**
   捨てると、博之の偽悪が一度も自分に請求されません。8/3 が「全員の嘘の利息」ではなく、ただの不幸になります。
3. **物の時計(タッパー・ジャケット・缶。ep1・0・12 → ep16・19・20)**
   捨てると、永劫が説明文になります。
4. **F21「美味い」の嘘(ep9 → ep12・14 → ep20)**
   これはリライトの引き金です。捨てると怒りの根拠が読者に届きません。
5. **斑鳩の缶12枚と「お前が数えろ」(ep4・12 → ep17)**
   オーナーの言う「数える癖が少し多い」への答えになっています。数える行為に意味を持たせる仕掛けです。
6. **F18 従属ロック→「今です、マスター」(ep7 → ep20)**
   檻の主従が逆転する瞬間です。ここが一番怖い場面です。

- ep6:成瀬の動機を一行足す(来賓への見せ物)。
- ep7:会議を名簿の一場面に圧縮する。
- ep8:皇の悶絶は3行にして、缶コーヒーを主役にする。
- ep9:戦闘は2行にする。

## 3. 反論(3つ)
1. **ep12 の白石の死を「成瀬の指示、博之の自責は誤り」にする案は、半分だけ受けます。**
   F2 の核は、博之の選択が博之に返ることです。全部を成瀬に移すと、博之の苦難が勘違いになって弱まります。折衷として、成瀬が通信車を前に出した事実は ep7 の名簿場面で仕込みます。ただ、手負いが白石の足を取ったことは動かしません。ヘイトは成瀬に溜め、責任は博之にも残します。
2. **ep6 を ep7 に吸収する案には反対です。**
   ep6 の「刃を自分でずらす」と「白石の袖」は、ep12 の袖の回収元です。ep5 と ep8 の日常統合までは飲みます。
3. **ep16〜18 の「疲労」は、息抜きではなく統合で処理します。**
   息を抜けば請求書が薄まります。ep17 と ep18 を1話にまとめて、8/3 は2話にします。重さは残したまま、密度で上げます。

## 4. 「もっと自由に」への答え(3つ)
1. **ep10 と ep11 の間に新設「営倉の一日」。**
   博之が規律違反で不在で、陽子とエリスだけの回にします。
   - エリスが初めて陽子に嘘をつきかけ、ログの空欄になります(F25 の種)。
   - 陽子は見ないふりを続けます。
   - 二人きりの安心スポットを、破局の直前に置く狙いです。
2. **ep15 で、斑鳩が博之のナイフの欠けの周りを整える。**
   ep4 の「周りを整えろ」の実演で、斑鳩の最後の授業にします。ナイフは ep19 で軽く折れます。オーナーの言う「傷ついて壊れて、最後に武器を研ぐ」構図が、斑鳩自身の弧になります。
   - 白石の札は、博之の缶ではなく斑鳩が持ち続けます。
   - 「あと2回だ」は、ここで言わせます。
3. **ep3 の末尾を逆転させる。**
   「転んだだけ、ね」を、陽子が博之より先に口にします。陽子が自分から嘘を渡す形になり、見ないふりの起点が陽子の能動になります。素案には無い改変で、後の録音場面(ep13)の効きが上がります。

## 5. 統合への提案:三嶋案から移植したい部品(最大5)
1. **タッパーの日付蓋と湯気の立つ飯**(ep13・ep16)。喪失を物の数で見せます。
2. **袖の連鎖**(白石 ep6・12 → 陽子 ep16 → エリス ep19)。拭く行為を物で渡します。
3. **砥石の「お前の分は彫らねえ」**(ep15)。斑鳩の研ぎ場面に合流させ、別れを言葉にしません。
4. **東雲の「黒田の手しか離さん」**(ep7 で匂わせ、ep18 で使う)。黒田排除の判断材料が補強されます。
5. **明け祭の規模**(ep14)。第4監視棟の地下旧貯蔵庫、約100畳、約40名と台詞で明示します。要決定ですが、数字は三嶋案を借ります。

## 6. 0部ラストの最終意見
- **永劫の長さ**:1万年は反対です。「10〜30年」には賛成寄りで、私は約30年(要決定)を推します。400日では、ジャケットの擦り切れもナイフ折れも成立しません。唐揚げは6個を5個にして、日数基準で節目を組み直します。
- **オーナー案(元の世界がハッピー→エリスの怒りでリライト)**:採ります。「窓を一度だけ」にも賛成です。エリス単独の三人称で、博之は寝ています。観測ログは3行、スメラギ生存と家庭までにとどめます。窓に陽子は映しません。虐めすぎるとオーナーの言う二部で生きてくれなくなります。
- **怒りの置き方**:「ズルい」ではなく、「幸福が博之を必要としていない」ことへの反応にします。引き金は二重で、窓の食卓の本物の「美味い」と、博之の血の味の嘘の「美味い」です。
- **除外理由の書き方**:ep21 の理由欄の空白の前に、【対象:マスター　崩壊確率 ■■%】を一行置きます。スメラギ・白石・斑鳩は連鎖で自動的に落ちます。陽子だけは「保留」を繰り返して妹化します。
- **要決定**:窓の世界でスメラギは生存なのに、新世界では存在しない。この食い違いをどう扱うか。「元の世界側にだけ残す」という両立案を推します。
