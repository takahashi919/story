## 1. 物語の進行（シーン構成）

### シーン1：泥の降下
- 場所・時間・天気：勝浦新都市の市街地。昼過ぎ。曇一時雨。海水の匂いがする雨が降り始めたところ
- 視点：一人称（博之）。A/B 対象
- 配合：戦闘 4:6 → 代償 8:2
- 起きること（事実）：
  1. 海魔の小規模群（数十〜百。具体数は本文で決める）が上陸。正規兵の第3班が陣形を組むが、雨中の海水で魔力が減衰し、障壁が削られて崩れる
  2. 博之は離れた屋上から見ている。参戦の命令は出ていない。部下のいない小隊長格なので、単独で動いても不自然ではない（決定ログ 2026-10-12）
  3. 一人の兵が鎌に追い詰められる。博之が降りて「お前」と呼びかけ、泥纏いの刃で外殻ごと融かす。流麗な剣技ではなく、刺突と腐食による破砕。地面がドス黒く侵食される
  4. 戦闘の途中で、想定より早く代償が来る（計算違い。決定ログ 2026-10-13）。旧人類数十億人の断末魔が逆流する。博之は膝をつき、黒いヘドロ混じりの胃液を水たまりに吐く。泥の刃が崩れる
  5. 刃が崩れた隙に、博之が手負いにしておくつもりだった1体が、近くの兵に届く。博之は間に合わず、兵が1人負傷する。博之はすぐ立て直して残りを抑え、「全部こっちの計算だった」という顔をする
  6. 助けられた兵は礼を言わない。後ずさりして「……バケモノ」とこぼす。負傷した兵の仲間も距離を取る
  7. 博之は群れを全滅させない。数体を手負いで残し、一度それを見てから背を向ける（理由は書かない）
- 博之が知ること・思い込むこと：負傷した兵に自分の計算違いが原因だと分かっているが、口には出さない。エリートの剣筋が崩れるのを見る視線が、やけに細かい（憧れの滲ませ。語らせない）。自分は「汚いから綺麗なニュースの邪魔」だと思っている。残した数体が、博之の侵食で細胞崩壊を始めていることは、博之自身は感覚で知っている
- 読者だけが知ること：なし（ここは博之の体感に寄せる。裏舞台はシーン3以降）
- 字数目安：1,300字

### シーン3：光の貴公子の吐き気
- 場所・時間・天気：同じ戦場。博之が膝をついている少し後。雨が一時強くなる
- 視点：三人称（スメラギ）。最初の一文で「皇征弦は」と名指す
- 配合：5:5（軍部・政治と内面）
- 起きること（事実）：
  1. 勝浦基地の主力が急行。先頭の皇征弦が『白銀・征弦』で、博之が残した手負いの数体を斬る。すでに崩壊を始めていた個体を、光で消すだけ
  2. 兵たちが「さすがは皇様」と歓声を上げる。皇は称賛が耳に刺さるたびに胃の奥から酸っぱいものがせり上がる。斬ったのは「残飯」で、勝敗は自分の来る前に決していた、と自分で分かっている（博之の仕込みが外から見える瞬間）
  3. 戦場の中央の惨状（融けた外殻、侵食された地面）と、その真ん中で膝をつく博之の背中を見る。「……黒田博之」
  4. 空が不自然に割れる（降下そのものは書かない。割れたところまでで終わる）
- 博之が知ること・思い込むこと：（一人称ではないので該当なし）
- 読者だけが知ること：皇は100%博之の手柄だと分かっている。博之が手負いを残した意図を、皇だけが外から見抜いている。負傷した兵のそばを通った時、博之の計算違いの跡(崩れた泥の刃の欠片)にも気づく
- 字数目安：700字

### シーン4：檻と飼い犬
- 場所・時間・天気：同じ戦場。降下の直後。繭の周囲数メートルだけ雨粒が止まる
- 視点：一人称（博之）
- 配合：戦闘・緊迫 4:6 → 会話のズレ 3:7
- 起きること（事実）：
  1. エリスの降下を博之の目から1回だけ書く。光の繭が割れ、白銀の髪の少女が全裸で降りる。博之は吐いた直後で、ろくに立てない
  2. 会話は2〜3往復だけ。エリス「あなたが、私の『檻（マスター）』ですか」→ 博之「まずは服を着ろ」→ エリス「理解不能」と名乗る：「デウスエクスマキナの端末『エリス』」。【判定】は【 】で、地の文で認定理由は説明しない
  3. 軍の隊長が「未確認の脅威」と叫び、射撃を命じる。隊長の台詞は命令形だけ。エリスは黒い結晶体で魔力弾を吸い込む。火花も散らない
  4. エリスが「低級な殺意を確認。環境の清浄化」と排除を始める。頭上に黒い渦
  5. 博之が走り、エリスの手首を掴む。ここで2度目の支払い：因子同士が触れて逆流がもう一度来る。博之は立ったまま歯を食いしばり、指先の痺れと口の中の泥と鉄の味に耐え、顔には出さない。エリスの手首の温度が、泥の自分の手より温かい
  6. 博之はジャケットを乱暴に被せ、エリスは「排除シーケンス、凍結」。皇は博之の視界の端にいるだけで、一言も喋らない
  7. 「飼い犬」宣言。短く突き放す形。「軍が押し付けた」とは言わない。軍に自分へ押し付けさせる未来形で言う（決定ログ 2026-10-13。例は「どうせ軍は持て余す。俺みたいなゴミに回すしかない獣だ」。正確な台詞は本文で詰める）
- 博之が知ること・思い込むこと：エリスが何者かは分からない。軍に連れて行かれれば検体にされると思っている（博之の推測。事実かどうかは後の話）。手首を掴めば止まる、という確証はなく、賭けた
- 読者だけが知ること：認定の理由（シーン2のログと、因子値の推移から読者が自分で結ぶ）
- 字数目安：1,600字

## 2. 各キャラの行動意図と背景

本文には直接書かない。地の文や台詞の選び方、仕草に滲ませる（`harness/オーナーの好み.md` 1〜2）。

- **博之**：自分が全部片付ければ、軍にとって「あってはならないイレギュラー」になる。だから手負いを残す。エリスは保護名目で検体として連れ去られる前に、自分の管理下に置く。そのために彼女を「飼い犬」と呼び、軍に手を出させない。自分の本心は嘘か否定でしか言わない
- **エリス**：博之の体内の因子を検知し、同調率100%で「檻（マスター）」と認定する。愛でも信頼でもなく、システム上の必然。感情はまだない。低級な殺意は「環境の清浄化」の対象
- **皇征弦**：手柄が博之のものだと100%分かっている。称賛が吐き気になる。エリスの圧に自分の光が霞んでいくのを感じて、動けない。エリスにも博之にも、この話では一言も話さない
- **正規兵の隊長・兵**：博之を「落ちこぼれ」「バケモノ」として扱う。助けられても礼は言わない。軍のプロトコルに登録のないエリスを「未確認の脅威」として撃つ
