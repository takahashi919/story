# 参照プロファイル（参考作家の数値）

3月に渡した【参考文章】（三嶋与夢①②、理不尽な孫の手）は、これまで `作家カルテ.md` の言葉としてしか効いていなかった。
ここでは参考文章を **数値** にして、書いた本文がどちらの作家にどれだけ寄っているか、どの指標がずれているかを測れるようにする。

- 数値：`参照プロファイル.json`（このフォルダ）。本文の抜粋は一切持たない。出典はファイルのハッシュだけ。
- 参考文章そのものは他の作家の著作物なので、リポジトリに入れない。

## 使い方

```sh
python3 harness/tools/measure.py --compare --scenes episodes/第0部/00_泥雨の異端者/本文.md
```

出力の読み方：

```
配合推定  孫の手 33 : 三嶋 67   距離 3.6（1.41 を超える ＝ どちらの作家にも似ていない指標がある）
  指標      本文  孫の手  三嶋  旧原稿  判定
  ……/万字  83.0   43.5  13.8   67.1  ✕ 目安より多い（20〜40）／両作家より多い（…）
  場面1 4679字 孫の手 0 : 三嶋 100 ...
```

- **配合推定**：0 なら三嶋、100 なら孫の手そのもの（作家本人の4,500字の塊の中央値で較正）。骨組みのシーンごとの「配合」（`本作の文体.md` の表、例：戦闘 4:6）と比べる。
- **距離**：配合で説明しきれないずれの大きさ。参考作家本人の塊の 90% は 1.41 以内に収まる。超えたら、どちらにも似ていない指標がある。判定の ✕ を見る。
- **判定**：
  - ✕ 目安より… → `本作の文体.md` の目安の外。
  - ✕ 両作家より… → 両作家の4,500字の塊の p10〜p90 の外。どちらの作家もそう書かない。
  - ○ 孫の手寄り／三嶋寄り → 範囲内で、どちらに近いか。
- **場面ごと**（`--scenes`）：＊＊＊ で区切った場面の配合。1,500字未満は揺れが大きいので参考扱い。

| 地の文一文平均 | 20.9 | 25.0 | 31.7 | 地の文の一文の長さ |

| 漢字率% | 23.5 | 26.5 | 32.7 | 画面の黒さ。高いと硬く読みにくい |
| ……/万字 | 43.5 | 13.8 | 67.1 | 間・ためらい |

旧原稿（3月の 00c と 01〜08）は、段落が長く、漢字が多く、地の文の一文が長く、「……」が多い。どれも **両作家のどちらにも似ていない** 方向で、配合の問題ではない（Gemini の癖が出ていたと読める）。

## 限界

- 数値は文体の **外形** しか見ない。面白さ、痛み、読者心理の操作は測れない。そこは三嶋・孫の手の提案と齊藤の調停で見る。
- 数値を目標にしない。書いた後の点検に使う（数値に合わせて「……」を足し引きするような直しはしない）。
- 参考文章は2作とも一人称、本作は三人称。会話比率は場面の中身でも大きく動く（戦闘は低く、監視棟の日常は高い）。
- 参考文章は一作家あたり1〜2作。作家の全体像ではない。

## 作り直す

参考文章を足した・差し替えた時。手元の zip（3月の制作物）から【参考文章】を取り出して、パスを渡す。

```sh
python3 harness/tools/build_profile.py \
  --magonote 【参考文章】理不尽な語の手.txt \
  --mishima 【参考文章】三嶋与夢①.txt 【参考文章】三嶋与夢②.txt \
  --old archive/2026-03_notebooklm/drafts/00c_* archive/2026-03_notebooklm/drafts/0[1-8]_*
```

目安（字数・会話比率・……・――・（））は `build_profile.py` の `TARGETS` と `本作の文体.md` の両方に書いてある。変える時は両方を直して作り直す。
