### B-3. 文末表現パターン（作家の呼吸リズム）

| 文末パターン | 無職転生 | モブせか | 悪徳領主 |
|-------------|---------|---------|---------|
| 〜た。（過去形断定） | 2,248 | 1,396 | 1,265 |

**分析結論:**
- **孫の手** = 「〜ない。」（否定形）が突出して多い → 主人公の自己否定・迷い・逡巡を文末で表現する癖。「〜のだ。」も多く、読者に語りかけるような説明調が特徴
- **三嶋** = 「〜いた。」（過去進行）が相対的に高い → 客観描写・状況説明が多い

### B-4. 接続詞の使い方（思考の繋ぎ方）

| 接続詞 | 無職転生(/万字) | モブせか(/万字) | 悪徳領主(/万字) |
|--------|----------------|----------------|----------------|
| だが | **11.5** | 9.1 | **12.6** |
| しかし | **7.9** | 2.4 | 3.1 |
| ただ | 7.6 | **6.8** | 5.5 |
| そして | 6.6 | 6.5 | 5.0 |
| いや、 | **4.8** | 3.1 | 1.8 |

**分析結論:**
- **孫の手** = 「だが」「しかし」「いや、」が多い → 逆接・自己訂正が多い文体。考えては否定し、否定しては考え直す、**螺旋的思考**の文体
- **三嶋（モブせか）** = 「だから」「まぁ」が多い → 因果説明と脱力系の繋ぎ。テンポよく流す文体
- **三嶋（悪徳領主）** = 「だが」が最多 → 三人称パートが増え、より硬質な語り口に

**分析結論:**
- **孫の手** = 触覚が他より2倍多い → 身体感覚に根ざした描写。痛み・温もり・肌触りで感情を語る

### C-2. クライマックスの作り方

**理不尽な孫の手：**
実テキストで確認された特徴として、クライマックスでは短文の連打で緊張感を高め、一文一文を改行で区切り、映画のカット割りのようなリズムになる。最終盤「俺はもう、満足だ」「十分、生きた」のように、短い断定文で感情を凝縮する。

**三嶋与夢：**
クライマックスでは会話の応酬が加速し、主人公の毒舌と相手の驚愕のテンポが上がる。「――」による場面カットが連続し、異なる視点からの同時進行描写で盛り上げる。勘違いの解消（または深化）が最大のカタルシスになる。

## G. 文体再現ガイド — AIへの具体的指示

### G-1. 理不尽な孫の手の文体を再現する場合

```
【文の長さ】
- 一文は平均22字前後を目標。文の半分以上は20字以下の短文
- 長文（60字以上）は全体の2%以下に抑える
- 短文を連打してリズムを作る

【会話と地の文の比率】
- 会話文は全体の17%程度（5行中1行以下）
- 地の文を厚く。心理描写・情景描写で埋める
- 会話は短く（平均21字）。56%を15字以下に

【記号の使い方】
- 三点リーダ「……」を多用（36.8回/万字）。ためらい・余韻・沈黙に
- ダッシュ「――」はほぼ使わない（1.4回/万字）
- 括弧モノローグ（）はほぼ使わない（0.7回/万字）。心の声は地の文に溶かす

【接続詞】
- 「だが」(11.5/万字) → 「しかし」(7.9) → 「ただ」(7.6) の順で多用
- 「いや、」(4.8/万字)で自己訂正する癖を入れる
- 逆接が多い = 思考が常に揺れている印象を与える

【文末】
- 「〜ない。」を意識的に多用（否定形で自己否定・迷いを表現）
- 「〜のだ。」で読者に語りかける説明調を混ぜる
- シリアス場面では短い断定文（「〜た。」「〜だ。」）の連打

【感情描写】
- 感情語を17.4回/万字程度。内面を丁寧に掘る
- 触覚描写（3.7/万字）を意識的に入れる。痛み・温もり・肌触り
- 前世の記憶とのリンクで現在の感情を立体化する
```

- 括弧モノローグ（）を積極使用（2.5〜4.6回/万字）。ツッコミ・本音を差し込む

【接続詞】
- 「だが」(9〜12.6/万字)が主力
- 「だから」(4.4〜6.6/万字)で因果をつなぐ
- 「まぁ」(0.9〜3.1/万字)で脱力感を出す
- 孫の手ほど逆接は多くない。流れを断ち切らず進む

【文末】
- 「〜いた。」（過去進行）の比率が高い → 客観的な状況描写
- 「〜だった。」で結果を提示するパターンが多い

【視点切り替え】
- 「――」や「◇」で頻繁に視点を切り替える
- 主人公の行動 → 周囲の反応（別視点）→ 読者に勘違いの構造を見せる
- 悪徳領主では案内人視点を挟み、三重の認識ギャップを作る

【コメディの入れ方】
- 主人公の真面目な行動/発言 → 周囲の過剰反応 → （本人無自覚）
- AI相棒の冷静なツッコミで緩急をつける
- 「いらんわ！」「お前って奴は！」等のテンプレ反応を活用
```

## H. 融合レシピ — 2名のブレンド指針

### H-1. 推奨ブレンド比率（用途別）

| 用途 | 孫の手 : 三嶋 | 狙い |
|------|---------------|------|
| **感動重視の長編** | 7 : 3 | 孫の手の深い人間ドラマに三嶋のテンポをスパイスに |
| **エンタメ重視のWeb連載** | 3 : 7 | 三嶋のテンポとギャグに孫の手の成長要素を深みに |
| **バランス型（推奨デフォルト）** | 5 : 5 | 両者の強みを等分に |

### H-2. 要素別の具体的配合

| 要素 | 採用元 | 具体的な数値目標 |
|------|--------|----------------|
| **一文の長さ** | ブレンド | 平均23〜25字（両者の中間） |
| **会話比率** | 三嶋寄り | 25〜30%（孫の手の17%と三嶋の36%の間） |
| **三点リーダ** | 孫の手寄り | 20〜25回/万字（シリアス場面で増やす） |
| **ダッシュ** | 三嶋寄り | 15〜20回/万字（場面転換に使う） |
| **括弧モノローグ** | 三嶋寄り | 2〜3回/万字（ツッコミ用） |
| **感情語** | 孫の手寄り | 15回/万字程度 |
| **接続詞の逆接率** | ブレンド | 「だが」10回/万字 +「いや、」3回/万字 |
| **視点切り替え** | 三嶋の手法 | 主人公視点 → 周囲の反応 → 第三者の評価 |
| **心理描写の深さ** | 孫の手 | シリアス場面では「……」で間を取り内面を掘る |
| **会話のテンポ** | 三嶋 | 日常場面では長めの会話でテンポよく |

### H-3. 章ごとの動的配合

| フェーズ | 孫:三嶋 | 文体の変化 |
|---------|---------|-----------|
| **序盤（導入）** | 3:7 | 会話多め、テンポ重視、世界観は会話で説明 |
| **中盤（関係深化）** | 6:4 | 地の文増加、「……」増加、触覚描写を入れる |
| **クライマックス前** | 5:5 | 視点切り替え増加、「――」で緊張感 |
| **クライマックス** | 4:6 | 短文連打 + 会話の応酬。爽快な決着 |
| **エピローグ** | 8:2 | 短い断定文、余韻、「……」で静かに締める |

### H-4. アンチパターン（避けるべき混ぜ方）

1. **「……」と「――」を同一段落内で多用** → 記号が喧嘩してリズムが崩壊
2. **螺旋思考（「いや、」「だが」連発）＋テンポよい会話劇** → 思考が重くて会話が軽い不協和
3. **括弧モノローグ（）＋三点リーダ地の文** → 心の声の表現方法が二重になり混乱
4. **孫の手式の長い内省 ＋ 三嶋式の頻繁な視点切り替え** → 没入が浅くなる

### H-5. 推奨する融合パターン

```
【パターンA：成長する勘違い主人公】
 文体設計:
  - 主人公視点 = 孫の手式（「……」多め、螺旋思考、内面描写厚い）
  - 周囲の反応パート = 三嶋式（「――」で切り替え、客観描写、勘違いコメディ）
  - AI相棒との会話 = 三嶋式（テンポよく、長めの台詞、ツッコミ）
  数値目標: 会話25%、三点リーダ22/万字、ダッシュ18/万字

【パターンB：家族ドラマ × 下克上】
 文体設計:
  - 家族シーン = 孫の手式（短い会話、触覚描写、感情語密）
  - 戦闘/政治シーン = 三嶋式（長めの会話、「――」で場面転換、爽快感）
  - ギャグパート = 三嶋式（（）でツッコミ、「まぁ」で脱力）
  数値目標: 会話28%、感情語16/万字、コメディ表現適度

【パターンC：SF大河 × 人生年代記】
 文体設計:
  - 幼少期パート = 孫の手式フル（短文、「……」、内省、家族描写）
  - 青年期パート = ブレンド（会話増加、AI相棒導入、冒険パート）
  - 壮年期パート = 三嶋式寄り（政治描写、三人称多め、スケール拡大）
  - 最終章 = 孫の手式（短い断定文、余韻、穏やかな死）
  数値目標: 章により可変（上記H-3参照）
