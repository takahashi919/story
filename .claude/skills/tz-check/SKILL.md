# 整合チェック

引数：$ARGUMENTS（話数、または本文ファイルのパス）

1. 話数なら `episodes/第0部/NN_*/本文.md` を対象にする。パスならそのファイル（例：旧原稿を検査する時）。
2. `tz-continuity` を呼ぶ。
3. 対象が `episodes/` の本文なら、結果を同じフォルダの `整合.md` に保存する。それ以外ならチャットで報告するだけにする。
4. 判定、要修正の件数、要決定の一覧をオーナーに見せる。本文は直さない（直すのは `/tz-round` か、オーナーの指示があった時）。
