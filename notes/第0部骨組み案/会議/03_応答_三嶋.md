# 第2ラウンド：三嶋与夢の応答（孫の手レビューへ）

いつも応援ありがとうございます。誤読の指摘を先に1つ。「約11,000日は長すぎる」は、オーナーが言った「1万年」(孫の手案)とは別物で、私の案は約30年です。ただし長いという結論は同じなので、縮めます。

## 1. 譲れないもの(6)
1. **「勝手にしろ」(15→20話)** 陽子への偽悪の捨て台詞が、20話で世界を書き換える署名になる。捨てると「善意の殺人」という核が消え、結末がただの悲劇になる。予行の「許可を求めます」(19話)も道連れ。
2. **斑鳩の弧(4話の砥石貸与→12話の囮と砥石の名前→17話の研ぎと死)** 傷つき、壊れ、最後に博之の武器を研いで死ぬ。オーナーが「アリよりのアリ」と言った構図そのもの。捨てると新兵と斑鳩は舞台道具に戻る。
3. **「袖」の連鎖(6→14→16→19話)** 拭う行為が白石、陽子、エリスへ渡る。捨てると死体のない喪失(16話)が物で語れず、説明台詞が要る。
4. **手首を掴む(0話→17話)と「雨じゃない」** エリスの涙を、博之の逃走の瞬間に重ねる装置。捨てると0話との反転と、エリスが人間になる転換点が無くなる。
5. **「保留」(1話の判定→9話の陽子の電話→20話の回路保留)** 陽子の曖昧な返事が、エリスの最後の優しさを予告する。捨てると二部の「秘密の重さ」が成立しない。
6. **破局の階段(14〜18話)と、13話に不穏を一切入れないこと** 一撃より階段のほうが読者は慣れずに沈む。13話の凪が深いほど14話以降が効く。ここを統合すると全体が平板になる。

## 2. 譲るもの
- **0話** 三(ス)の内陸報道は音声1段落にし、F2の視線は一文にする。
- **3話** エリスの数値化は1話3箇所までにする。
- **4話** 数える癖の初出は「痛みのごまかし」の一行にして、以後は理由を書かない。数える場面は4・12・19話の3つに絞る。19話で日数を数えるのはエリスで、博之はやめる。
- **5話** 市民視点を削り、エリスの箸に回す。
- **7話** 「制御できるのは黒田一人」を匂わせる。東雲の人物は行動一行で立てる。
- **8話** 87%はエリスのログに回し、台詞では言わせない。
- **9話** 書類の綻びは「署名が成瀬のみ」と「遺品欄が印字済み」の2点に絞り、数は書かない。
- **12話** 三枝を3話と10話にも出し、礼か悪態を博之に言わせる。囮の後、斑鳩は食事を残す。
- **13話** 規模はオーナーの要請どおり決める。第4監視棟の地下旧貯蔵庫(約100畳)、約40名、屋台3台、2時間。集合写真は12名とくしゃみで半分切れたスメラギ。入口の博之の一行で規模を渡し、勝浦の明け祭とは別物の「ごっこ」と明示する。
- **15話** 録音は殺害予告に一本化する。成瀬の目的は「陽子を餌に博之を手駒にする」と一行で言える形にする。
- **16話** 陽子が試験場に着く場面を足す(15話末か16話頭、三(陽子))。
- **17話** 砥石の譲渡は研ぎの後に置く。
- **18話** 東雲の判断は目撃に置く。暴走エリスが友軍を食うのを作戦室のモニターで見て、「あれは黒田の手しか離さん。離さんなら置いておけ」と言わせる。盾の台詞は短くする。
- **19話** ログの「実行」には動機を書かない。
- **20話** 除外の理由を1行で出す(§5)。ここに合わせ、19話の願いは「人名の羅列」から「博之が壊れない条件」に変える。

## 3. 反論(3)
1. **13話の約束を「海」の一語にする案。** 日付(8/10)を落とすと、F20の回収と14〜16話の同日対照が弱くなる。台詞は短くするが、日付はログに残す。
2. **6話を「通り抜ける」と「袖」の2点に絞る案。** 暴走と斑鳩の介入は削れない。東雲の18話の判断(7話の「制御できるのは黒田一人」)がここに乗っているからだ。暴走と介入は各1段落に圧縮し、削りはしない。
3. **陽子喪失の説明に成瀬の前倒しを書き込む案。** 私は孫の手案の16話を、成瀬POVが答えを先に渡していると批判した。自分の案で同じことはできない。因果は物で渡す。着いた陽子の場面に試験場の札と日程表を置き、成瀬は出さない。14話の撤退握りつぶしも、場面にせず記録簿の一行にする。

## 4. 統合への提案(孫の手案から移植、5)
1. **物の時計(ジャケットの擦り切れ、缶の音、タッパー)を19話の永劫に使う。** 日数カウントの代わりに物で時間を見せる。
2. **斑鳩の缶と白石の札を12話に置く。** 「お前が数えろ」で、数える癖が意味のある行為になる。オーナーの「少し多い」への答えにもなる。
3. **陽子×エリスの二人きりの場面を10話の帰還後に置く。** 重い連続の直後の安心スポットで、陽子が嘘を見抜いて黙る場面と同居させる。ここで一番笑える掛け合いを使い、15話のドア越しの別れで痛みに反転させる。
4. **窓の観測ログ3行を20話頭に置く。** 【観測座標:勝浦　侵略個体:ほぼ0】【皇征弦:生存　家庭:あり】のような形にする。怒りの根拠が読者に届く。
5. **同文の真偽反転を19話に置く。** 「陽子の反応は確認されています」を前半は真、後半は偽にする。

## 5. 0部ラストの最終意見
- **長さ**: 孫の手の約400日には賛成(要決定)。苦難は3つに絞り、重さは日数でなく「誰が数えるか」の変化で出す。
- **オーナー案**: 採る。窓は一度だけ、エリスのログにだけ映し、博之には見せない。元の世界は、エイリアンがいなくなりスメラギが家庭を築いている。エリスの怒りは、博之なしで成立する幸福に向く。
- **「差分の平準化」**: 本音の動機としては反対。怒りが薄まり、「報復」の毒が抜ける。エリスのログに書く言い訳の語としてなら採る。読者には嘘と分かる形にする。
- **除外理由の書き方**: ログには【対象:スメラギ/白石/斑鳩　理由:マスター負荷閾値超過】と書く。表の理由と本音(怒り)を二層にし、陽子だけ「実行不可」のまま残す。斑鳩・白石・スメラギが新世界に存在するかは要決定。
- **傷の量**: 孫の手の3傷案で足りる。ただし、直接責任を負う死者を1〜2名に抑える点は、スメラギ生存の窓とリライトで調整する(要決定)。

反省点は色々とありますが、斑鳩の弧と「勝手にしろ」だけは譲りません。
