# canon — 正史

この物語の設定は **ここにしか書かない**。チャットで決まったことも、ここに書くまでは決定ではない。
ひとつの事実はひとつのファイルにだけ置き、他のファイルからはリンクで参照する（同じことを二か所に書くと、片方だけ直されて食い違う）。

## 正本の優先順位

1. この `canon/`（作者と合意したもの）
2. `sources/02_防人めも.md`・`sources/03_1980年以降年表.md`：**正史**（2026-10-12 オーナー指定）
3. `sources/01_キャラクター設定書_改訂版.md`：**第1部の草案**。肉付けの土台
4. `archive/2026-03_notebooklm/`：3月の作家会議と旧原稿。オーナーが採用した内容だけが有効
5. `sources/04_新規案年表_前時代.md`：前時代史

上位と下位が食い違ったら上位が正。canon 自体に穴や矛盾を見つけたら、勝手に埋めずに `決定ログ.md` の「未決」に積んで作者に聞く。

## 書き方の約束

- 確度を書き分ける：**確定**（オーナーが決めた）／**仮**（提案中・作者未承認）／**未決**（決まっていない）。
- 出典を書く：`(決定ログ 2026-10-12)`、`(mtg/4)`、`(sources/03 8/5)` のように。
- 本文（`episodes/`）に書かれたことは canon ではない。本文で新しく生まれた設定は、調停のあと canon に移して初めて正史になる。
