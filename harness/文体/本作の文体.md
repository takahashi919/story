# 本作の文体

土台は `作家カルテ.md`（孫の手 × 三嶋のブレンド指針）。ここには本作だけの約束を書く。

## 配合

シーンの性質で動的に変える（`作家カルテ.md` H-3、novel-generator スキルの C-1 表）。第0部の目安:

| シーン | 孫の手:三嶋 | 例 |
|---|---|---|
| 戦闘・蹂躙 | 4:6 | 0話前半、3話の囮戦術。短文連打と「――」 |
| 代償・嘔吐・内面 | 8:2 | 0話の路地裏。「……」で間を取り、物質的に書く |
| 監視棟の日常 | 3:7 | 唐揚げ、シャツの圧縮。会話のテンポ、エリスのズレ |
| 陽子・斑鳩との情 | 7:3 | 4話の手当て、「死ぬなよ」。触覚と短い会話 |
| 軍部・政治 | 5:5 | 7話の会議。長めの台詞に情報を載せる |
| 観測ログ（幕間） | ― | システムの文体。感情語を使わずに感情を見せる |

3月の初稿の方針（mtg/0 齊藤裁定）：読みやすさの外装とテンポは三嶋、忘れられない痛みの内装は孫の手。

## 視点（決定ログ 2026-10-12）

**骨組みは三人称（客観の事実）、本文は博之の一人称。** 見えないものは三人称の裏舞台と観測ログで見せる。

| 層 | 書き方 | 何を受け持つか |
|---|---|---|
| 博之パート | 一人称「俺」。博之が見て、触れて、思い込んだことだけ | 戦場の体感、代償、日常、勘違い |
| 裏舞台 | 三人称。視点人物を一人に固定（スメラギ、斑鳩、陽子、成瀬、軍部・内陸など） | 博之が見られないもの：外から見た博之の異質さ、軍部の判断、プロパガンダと蜜を吸う者たち |
| 観測ログ（幕間） | エリスのシステムログ | エリスの内側（感情語を使わずに） |

- 一人称と三人称の配分は話ごとに決める（骨組みの「視点の配分」）。各話の結果を見てバランスを調整する。
- 第0話の冒頭で一人称版と三人称版を書き比べた（A/B。`episodes/第0部/00_泥雨の異端者/AB/`）。**結果：オーナーは一人称（A）を選んだ**（決定ログ 2026-10-12）。一人称で書き直す。測定では、一人称にすると文が長くなり（地の文一文平均 15.1→18.5）、短文率（45.6→39.1%）と漢字率（33.2→31.8%）が下がり、配合推定が孫の手寄りに動いた（38:62→50:50）。どちらも短文率・漢字率はまだ参考作家の範囲の外。

### 一人称の約束

- **博之は他人のことは評してよい。自分の本心は、嘘か否定しか言わない。** 「俺がこうしたのは〜だからだ」と自分の動機を正直に解説しない（オーナーの好み 1・2）。刀への憧れは、目が刀の扱いを追ってしまう描写と、「長くしたいからしてるだけだ」という言い訳で見せる（mtg/3 のオーナー案）。
- **博之が知らないことは書かない。** 他人の内心、見ていない場所、軍の本当の思惑、父の本当の意図。読者に見せたいなら裏舞台か観測ログへ回す。
- **勘違いは勘違いのまま書く。** 博之の思い込み（父の言葉など）を地の文で訂正しない。訂正は他の人物（陽子の回想など）にさせる。
- **自己卑下を毎ページ続けない。** 皮肉、悪態、エリスへのツッコミで声の幅を出す。
- 体感は物質で書く（オーナーの好み 3）。痛み、吐き気、泥の重さ、骨の軋み。

### 形式

- 場面の頭に視点の印を書く：`<!-- 視点: 一人称 -->`、`<!-- 視点: 三人称（スメラギ） -->`、`<!-- 視点: 観測ログ -->`。印は場面ごとに書く（測定と整合チェックが使う）。
- 三人称の場面は、最初の一文で視点人物が分かるようにする（一人称との切り替えで読者を迷わせない）。
- 場面転換は空行と「＊＊＊」（旧原稿 00c に合わせる）。
- （ ）モノローグは一人称では基本的に要らない。三人称の場面で使う時は、1万字あたり2〜6回程度に抑える。
- Web 小説の形式：段落は短く、会話は改行で分ける。空行を多めに。
- エリスのシステム表示は【 】で囲む（例：【判定：マスター（檻）として認定】）。観測ログの書式は `canon/構成/全体構成.md`。
- 数字は算用数字（1980年、5月4日、87%）。

## 数値の確認

書き終えたら必ず `python3 harness/tools/measure.py --compare --scenes <本文>` で測る。字数をモデルの目算で書かない。
目安：字数 3,500〜5,000。会話比率 25〜35%。「……」20〜40/万字（シリアス回は上振れしてよい）。「――」15〜25/万字。（）6/万字以下。
（この目安は `harness/tools/build_profile.py` の `TARGETS` にも書いてある。変える時は両方を直し、プロファイルを作り直す。）

`--compare` は、一人称の場面（視点の印で判別）だけを、参考文章から作った数値（`参照プロファイル.md`）と比べて、孫の手:三嶋 の配合推定と、目安や両作家の範囲から外れた指標を出す。`--scenes` は場面ごとの配合。骨組みのシーンごとの「配合」と比べる。
旧原稿は「……」が 40〜80/万字と多く、段落が長く、漢字が多い。どれも両作家のどちらにも似ていない方向。同じ癖が出ていないか、提案の段で見る。
数値は点検に使い、目標にしない（数値に合わせて記号を足し引きする直しはしない）。
