# 報復のツァラトゥストラ — SAKIMORI（防人）

> これは、世界を一つ殺して作られた、最高に狂ったハッピーエンド。

NotebookLM / Gemini で書いていた物語を、Claude と一緒に書き直すためのリポジトリ。

1980年（新西暦）、千葉・勝浦。海水を含んだ雨の日にだけエイリアンが上陸する。
悪魔の王の因子を宿した「泥を啜る」少年・黒田博之と、空から降ってきたデウスエクスマキナの端末・エリス。
コンクリートの監視棟で育った歪な疑似家族は、8月に理不尽に壊される。
そして世界は、エリスの手で書き換えられる。
