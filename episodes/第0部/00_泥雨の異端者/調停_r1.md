# 第0話 調停 r1（齊藤陽介）

## 方針

オーナーの採用が全部筋通ってるから、今回は引き算が仕事。屋上は三嶋案1が軸。孫の手案1からは「釦を押して雑音が返る」という手の動作だけもらう。モノローグは4か所に一本化する。数えるものは「博之の勘定」と「スメラギの勘定」の二つに絞って、数のモチーフで繋ぐ。字数は4,700字着地。会話比率は物理的に18%に届かない。そこは正直に言う（下記）。

## 衝突の解き方

### 1. 屋上の受令機
- 合成する。釦を押して応える者がいない動作は、オーナーの「無線で指示する相手がいない」そのもの。三嶋案1の「兵の無線が鳴る→博之は雑音」と同じ位置に入る。
- 他の小隊の応答は「」で書かない。「雑音の向こうで誰かが短く応える」という音で処理する。台詞を持つ人数は増えない。
- 小隊の符号は引用しない。「符号を順に呼ぶ」とだけ書く。実際の小隊命名法則が未決なので、番号型や色型を本文で決めてしまわないため。
- 兵の無線応答は「了解」程度。

### 2. モノローグ（三嶋4か所と孫の手3か所の重なり）
一本化して4か所、計約700字。

| # | 場所 | 量 | 中身（事実だけ） |
|---|---|---|---|
| M1 | S1：兵が去った後、受令機を投げる前 | 約300字（旧の通り描写25〜31行を吸収するので純増は約130） | 高さ四階。二列の刀と障壁。正面の群れは十五。残りは横道へ逸れていく影。列のどこにも自分の位置はない |
| M2 | S2：吐いた直後 | 約140字 | 倒した数を数える。数えないと逆流の中で何体目か分からなくなる、手が先に覚える、という身体の感覚だけ |
| M3 | S4：杭が崩れた直後 | 約180字 | 兵が撃っても杭は向きを変えなかった。自分の声では止まった。手首は細い。ここに（……聞くのか）を1回だけ置く |
| M4 | S7：刃こぼれをなぞる間 | 約90字 | 「八体倒し、七体が残った」。数えるのは癖、とだけ |

- M4の動詞は「残った」にする。「残した」にすると意図になる。骨組みの「残したとも、残るしかなかったとも読める」余白を守る。
- 書かない語：「だから」「〜ために」「本当は」「わざと」「譲る」「手柄」「憧れ」「飼い犬」。動機を匂わせる接続は一切入れない。
- （ ）の内心は全体で1回（（……聞くのか））。スメラギの（俺が斬ったのは、残飯だ）は地の文の勘定に溶かすので（ ）は消える。
- 取りこぼしなし：孫の手(a)は M1 に統合、(b)は M3、(c)は M4。三嶋の「隔離室0〜100字」は M4 の90字で吸収。

### 3. 文の長短と会話比率
- 長文にするのは孫の手の指定4か所だけ。冒頭の雨、力の逆流、杭の観察、スメラギの勘定。
- 戦闘の動作連打（踏み込む。刺す。崩す）は短文のまま。全編を中文に上げると蹂躙のテンポが死ぬ。
- 会話比率：現状10.2%。追加できる台詞は、屋上3行、救出直後1行、兵が撃ちながら叫ぶ1〜2行、歓声3〜4行、廊下の「……はい」で約210字。計算上は13〜15%に着地する。
- 18〜22%は、S5・S7が台詞なしの設計と、3人縛りがある限り届かない。水増しすると緊張が崩れる。数字は追わない。`measure.py` の結果を整合.mdに記録して、15%未満なら追加枠から足す。足す順は、兵の叫び、屋上の博之の一言。

### 4. 台詞3人縛りとの整合
- 縛りは骨組みでS4（中央の対峙）にかかっている。博之・エリス・あの兵の3人。S2〜S4は守る。
- S5の歓声は、名前もタグもない群衆の声として書く（個人の台詞持ちにはしない）。
- S6の廊下の兵は、屋上のあの兵と同一人物にする（要確認Q5）。右手に包帯、膝に青い紐の巻かれた折れた柄、という物で同一人物だと伝わる。

### 5. あだ名と屋上の台詞
- 使うのは3回に限る：①屋上の無線の後に「ゼロ番隊長」②屋上の去り際に「隊長殿」③救出直後に「ゼロ番隊長」。
- 台詞（確定）：
  - 風上の縁から、鼻の前で手を振りながら、一文：「潮か泥か、お前が風下にいると区別もつかん」
  - 博之が釦を押して雑音が返った後、兵：「呼んでも誰も出んぞ、ゼロ番隊長」
  - 階段の扉の前で：「隊長殿の出番は、片付いた後の掃除だ。そこで大人しくしてろ」
  - 救出直後、「……離せ」の後に：「手柄稼ぎか、ゼロ番隊長」。博之は「死にたきゃ後でやれ」で返す。「礼は言わなかった。」の地の文は削る。
- 「ゼロ番」の由来は本文で説明しない。読者が無線のシーンで拾う。
- 「犠牲者ゼロ」との響きは強調しない。
- 斑鳩はこの呼称を使わない。S6に呼称は出さない。

### シーン構成 Before → After

#### S1 屋上（目標約950字）
- 冒頭の雨：「雨は横から来た。」の1行は残す。「細い糸」は削り、強い雨に直す。風、頬の痛み、口の塩、潮の匂いを、息継ぎなしの1文にする（長文①）。「雨幕」「ずぶ濡れ」「水たまり」は使ってよい。
- 縁の描写は短くして、下で二列の刀が障壁を張っていることだけを置く。
- 兵が上がってくる時点で、刀の柄の青い紐を出す。
- 兵は風上の縁へ回る（「わざわざ対角まで」は削る）。博之が風下になる。
- 嘲りの一文は、直後の動作で話者を固定する（鼻の前の手）。
- 受令機：兵の受令機が鳴り、符号を順に呼ぶ。兵が応答する。博之の腰の受令機は雑音だけ。博之が送信釦を押し、「こちら」と言いかけてやめる。指を離すと雑音が少し大きくなった気がする。そこで兵の「呼んでも誰も出んぞ、ゼロ番隊長」。
- 去り際：階段の扉の前で「隊長殿の出番は、〜」。
- 削除：「腰の受令機は雑音しか吐かない。〜名簿に名前が載るのは戦死者だけだ。」の3文。「数十。百に届くかもしれない」の1文。通りの描写の重複部分。
- 兵が去った後、M1。その後に受令機を外して投げる。縁を蹴る。

#### S2 降下〜失敗〜立て直し（目標約900字）
- 着地：膝が鳴る。水たまりが脛まで来る冷たさ。跳ねた泥水が口に入る塩気。
- 兵：膝をつく。折れた柄に青い紐。
- 泥と雨：強い雨に打たれても足元の黒は薄まらない。水たまりの上で油のように縁を保って滲む。「雨ではない。雨は透明だ。」は残す。
- 力の逆流：「熱した鉄串」「数十億の声」「悲鳴・祈り・赤ん坊の泣き声」「背骨・肩・肘」「ヘドロ」を、息継ぎなしの1文に（長文②）。
- 吐く：黒い筋の混じった胃液が、水たまりに落ちてもすぐには散らず、渦を巻いて残る。
- ナイフを雨に晒す1行（泥は落ちない）。S7の「拭っても滲む」に繋ぐ。
- 吐いた直後に M2。
- 「刃を引いた」「膝が落ちた」の理由は一切足さない。手負いは「七体」と数で書く。

#### S3 光の繭（目標約480字）
- 「少女は首を傾けた」は削る。「理解不能です」だけで受ける。
- 他は現状維持（名乗り、【 】、「まずは服を着ろ」）。

#### S4 破壊の権化と止まる手（目標約1,000字）
- 杭の描写（長文③）：地面の割れ方、貫かれた外殻から雨が落ちる速さ、刀を見る人間の視線の細かさ。憧れという語は使わない。
- 杭は足元から横道の奥へ向かって地面を割って走る。「横道から流れ込んできた」は削る。奥の影が消えていく。死骸が残るか否かは書かない。
- 手負いの七体も、いつの間にか唸っていない。
- 兵が撃ち続ける：折れた刀を投げ捨て、柄の青い紐が水たまりに落ちる。台詞は「来るな」程度を1〜2行足してよい。
- 「止めろ」→ 杭が崩れる → エリスは止まる → M3。
- 「理由を求めます」「うるさい。……黙れ」「返事はなかった。杭もなかった。」は残す。
- 「聞くのか。俺の言うことは。」の重複行は削る。「なんだか分からない。分からないが、聞いた。」は残す。
- 手首を離す：「博之は手首を離した。握っていた指が、すぐには開かなかった。」を、ジャケットを脱ぐ前に入れる。
- ジャケット：雨と吐瀉物で重くなった布は、肩に落ちずに貼りつく。少女は震えない。
- 「不思議そうに眺めていた」は削り、行動に直す（「襟を指でつまみ、布の目を調べるように見ていた」の方向）。
- 「俺が拾った。鎖は俺が持つ。噛まれたくなきゃ寄るな」は一字も変えない。飼い犬の語は足さない。

#### S5 スメラギ（目標約640字）
- 台詞なし。視点はスメラギ固定。
- 「この別働群は、中央の群れとは別に回ってきた」は削る。スメラギは群れが割れたことを知らない。「斥候の報せでは、この通りへ向かうのは八十」から入る。
- 圧が弱まる。押し返す。「息を整えて周囲を見渡した」は削る。
- 勘定（長文④）：斥候は八十。足元の残骸は数えて十二。立っているのは九。足りない六十近くはどこへ消えたのか。理由は書かない。
- 「刀の先で触れる→中身が抜けた殻のように崩れる」の一連は削除し、「最後の一体は他と同じ硬さだった。斬り下ろすと光に散った」に差し替える。弱体化させず、比喩も使わない。
- 歓声：群衆の声として3〜4行（「皇様だ！」「さすがだ、あの数を一人で」）。
- 「（俺が斬ったのは、残飯だ）」は削る。地の文にする：「自分が相手にするはずだった数は、八十だ。」。数が合わない感覚を載せる。（ ）は使わない。
- 「恐怖と、それとは別の何か」は削る。「嫌悪と、恐怖。喉の奥で絡まって、どちらが先に上がってくるのか分からなかった」の方向。

#### S6 編集された勝利と濁った声（目標約380字）
- スクリーン：「皇征弦、海魔を撃退。犠牲者ゼロ」。子どもの肩車と歓声は削る。
- 廊下：担架は広げたものが三つ。布が被せてあるのは二つ（要確認Q2）。濡れた靴の跡。
- 座る兵：右手に包帯。膝に、青い紐の巻かれた折れた柄。
- 斑鳩：「姿は見えなかった」は削る。兵の視線は床。見えるのは革靴の先だけ。顔、体格、傷は書かない。
- 台詞：「今日の記録は、俺が見るまで誰にも渡すな」。兵が「……はい」と返す。
- 呼称は出さない。

#### S7 隔離室（目標約350字）
- 夜は実測どおり「時々雨」。強雨は昼の戦闘だけ。壁の向こうの雨音は、強弱をつける。
- 刃の泥は拭っても滲む。S2の晒した場面と対にする。
- M4。
- 手のひらの包帯は端がはみ出している、の1行は短く。台車、赤いランプ、エリスの直立は現状維持。何も言わせず切る。
