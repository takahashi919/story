# 第0話：泥雨の異端者（MTG4 最終稿・組み立て）

## 前編

１９８０年、新西暦。 千葉県、勝浦新都市を叩く雨には、鼻腔を突き刺すようなひどい潮の匂いが混じっていた。 本来、初夏の雨は土の匂いや草の香りを運ぶものだ。だが、この街に降る雨は違う。太平洋の深淵から這い上がってきた異形のモノたちの粘液と、死に絶えた海洋生物の腐敗臭が混ざり合った、呪いの雫だ。

『雨の日、空から海水の匂いが降る時、奴らはやってくる』

勝浦新都市に住む魔闘士――『防人（さきもり）』たちにとって、それは生存を賭けた絶対のルールだった。

「陣形を崩すな！ 第３班、魔力障壁を維持しろ！ 抜かせるなッ！」

アスファルトの上で、泥にまみれた純白の制服が躍動していた。 防人のエリート候補生たちだ。彼らが掲げる手のひらからは、新人類の証である青白い魔力の光が放たれ、雨幕を切り裂いていく。 だが、その光はどこか頼りない。雨に混じる高濃度の海水が魔力を乱反射させ、その威力を削いでいるのだ。

「駄目です！ 障壁が削られる……こいつら、雨を吸って硬度を上げている！」

悲鳴と怒号が、叩きつける雨音に掻き消される。 彼らの視線の先には、海洋生物の遺伝子をグロテスクに肥大化させ、鋼鉄のような外殻を纏ったエイリアン――『海魔（かいま）』の群れがいた。 数十体のエイリアンが、不快な駆動音を立てながら、防人の美しい陣形を紙屑のように蹂躙していく。

その戦場を、少し離れたビルの屋上から見下ろしている少年がいた。 黒田博之。 防人の制服を着てはいるが、その着こなしはだらしなく、どこか世の中を捨てたような冷めた瞳を戦場に向けている。

（……相変わらず、綺麗なお遊戯だこと。教科書通りに並んで、海水で魔力が減衰することも計算に入ってねえ。あんなのが『人類の希望』かよ）

博之はポケットに手を突っ込んだまま、吐き捨てるように独りごちた。 眼下で死にかけているのは、自分を「落ちこぼれ」と嘲笑ってきたエリートたちだ。

「くそっ……俺たちは『選ばれた新人類』のはずだろ！ なんでこんな、言葉も通じないバケモノに……ッ！」

一人の候補生が、折れた剣を杖代わりに立ち上がろうとした時、その背後に巨大なエイリアンの鎌が振り下ろされようとしていた。

「おい、お前」

冷淡な声が、雨音を貫いた。 候補生が顔を上げると、いつの間にか戦場のど真ん中に、一人の少年が立っていた。 傘もささず、ずぶ濡れのまま。

「博之！？ お前、何しに……ここは参謀科の落ちこぼれが来る場所じゃない！ 逃げろ！」

「逃げる？ 誰が」

博之はひらひらと片手を振った。 その瞬間、周囲の空気が重く沈み、物理的な重圧となってアスファルトを軋ませた。

――グチャリ。

博之の足元から、防人たちの輝かしい魔力とは対極にある、ヘドロのように黒く禍々しい『力』が噴出した。 その泥は博之の右手に集い、形を成していく。 それは刀と呼ぶにはあまりに不恰好で、境界線が絶えず揺らめく、ヘドロの塊を無理やり研ぎ澄ませたような\*\*『泥纏いの刃』\*\*だった。

「ギ、ギィィイイイイッ！？」

鋼鉄の外殻を持つはずのエイリアンたちが、本能的な恐怖を露わにした。 博之が一歩踏み出す。 流麗な剣技などない。ただ、泥の刃を叩きつける。 だが、その一撃が触れた瞬間、エイリアンの強固な装甲はバターのように融解し、内部の肉ごと腐食して霧散した。

それは戦闘ですらなかった。醜悪な蹂躙。 博之がその『力』を行使するたび、周囲の地面はドス黒い泥に侵食され、美しい戦場は地獄の底へと変貌していく。

（……ああ、クソ。頭が割れそうだ）

力を行使した瞬間、いつもの『支払い』が始まった。 博之の脳内に、暴力的なまでのノイズが流れ込む。かつてこの星を滅ぼした旧人類――数十億人が同時に殺戮された時の、圧縮された絶望の記憶だ。

断末魔。祈り。呪詛。赤ん坊の泣き声。 脳髄を直接、熱せられた鉄串でかき回されるような激痛。博之の視界は血のような赤に染まり、平衡感覚が消失していく。

「ガハッ……ッ、オェッ……！！」

博之は膝をつき、水たまりの中に胃液をぶちまけた。 吐瀉物はヘドロのような黒い色が混じり、鼻を突く異臭を放つ。 彼の手から泥の刃が崩れ落ち、ただの汚濁となってアスファルトに溶けていく。

「……ハァ、ハァ……あと……数体か。……残りは、エリート様が美味しく頂けよ」

博之は、全滅させなかった。 意図的に数体のエイリアンを、手負いの状態で放置した。 自分がこの場をすべて片付けてしまえば、軍部にとって「あってはならないイレギュラー」として処分されるリスクがある。何より、あの綺麗な王子様に『花』を持たせてやらなければ、この街の平和という建前が維持できない。

泥水を啜りながら、博之は自嘲気味に笑った。 「俺は汚いから、綺麗なニュースの邪魔なんだよ……」

その時だった。

不自然に、雨が止んだ。 いや、博之の周囲数メートルだけ、雨粒が空中で静止し、何かに弾かれたように霧散している。

「……？」

激痛に耐えながら博之が顔を上げると、そこには空中に浮かぶ光の繭があった。 繭は音もなく割れ、中から一人の少女がゆっくりと降りてきた。

月光を溶かしたような白銀の髪。 透き通るような白い肌。一切の衣服を纏わず、ただ光のベールだけで包まれている。 その美しさは、博之が吐き出したヘドロの匂い漂う戦場において、あまりに異質で、あまりに残酷だった。

少女は無機質な、そしてどこか壊れたオルゴールのような声で告げた。

『――デウスエクスマキナ、プロトコルを解除。マスター、待機状態を確認しました。当該座標における「不浄な力」の根絶を……あ……』

少女の瞳が、泥まみれの博之を捉えた瞬間、その無機質な言葉が途切れた。

『……マスター……？ いいえ、あなたは……』

彼女の瞳の中で、青い回路のような光が激しく明滅する。 博之は口端を汚したまま、全裸の少女を見上げ、呆れたように笑った。

「……ちっ。最悪だ。バケモノの次は、全裸の迷子かよ……」

これが、世界を一度殺して作られた、最高に狂った物語の始まりだった。

## 後編

「……総員、突撃！ 残党を逃すな！ 皇（すめらぎ）様に続け！」

泥雨を切り裂き、重厚な軍靴の音が響き渡る。 勝浦基地から急行した防人の主力部隊。その先頭で、一振りの「刀」が白銀の残光を描いた。

『白銀・征弦（しろがね・せいげん）』

皇家の家宝であり、純度百パーセントの魔力伝導率を誇るその宝刀が振るわれるたび、不純な海水が浄化され、まばゆい光の粒子が戦場を包み込む。 その刀を振るう少年、\*\*皇 征弦（スメラギ・セイゲン）\*\*は、一分の隙もない動作で残ったエイリアンへと肉薄した。

「はぁっ！」

スメラギが踏み込む。 博之がわざと致命傷を避け、手負いで残した数体のエイリアン。彼らはすでに博之の「泥」に侵食され、細胞レベルで崩壊を始めていた。スメラギの放つ美しい一閃がその巨体に触れた瞬間、エイリアンたちは苦しむ様子もなく、聖なる光に包まれて消滅した。

「すごい……さすがは皇様だ！」 「我ら防人の誇り、光の貴公子……！」

先ほどまで死を覚悟していた候補生たちが、手のひらを返したように歓声を上げる。 彼らの瞳に映っているのは、雨の中でも気高く輝くスメラギの姿だけだ。

だが、当のスメラギは、その歓声が鼓膜を叩くたびに、胃の奥から酸っぱいものがせり上がるのを必死に堪えていた。

（……違う。俺が斬ったのは、すでに死に体だった『残飯』だ。俺が来る前に、この場の『勝敗』は決していた）

スメラギの鋭い視線が、戦場の中央に広がる「異様な惨状」を捉える。 そこには、光の魔法では説明のつかない、抉り取られたようなエイリアンの肉片。そして、その汚濁の中心で、膝をつき、どす黒い吐瀉物をぶちまけている少年の背中。

「……黒田、博之」

スメラギがその名を震える声で呟いた瞬間、上空の「雨」が、不自然に割れた。

――キィィィィィン、と。

鼓膜を突き刺す高周波。 光の繭が割れ、そこから一人の少女がゆっくりと降りてきた。 衣服を纏わぬ、白銀の髪の少女。そのあまりの神々しさと、同時に感じる「理解不能な圧」に、現場の兵士たちが凍りつく。

「未確認の脅威（コード・アンノウン）を検知！ 射撃用意ッ！」

増援部隊の隊長が叫ぶ。軍のプロトコルに、白銀の髪をなびかせ宙に浮く少女のデータはない。 「光」でも「泥」でもない、ただ圧倒的な「死」を予感させる異物。 兵士たちは恐怖を塗り潰すように、一斉に魔力弾を放った。

数十発の青白い光弾が、雨幕を切り裂き少女へ殺到する。 だが、着弾の衝撃音は響かなかった。

少女が指先をわずかに動かすと、彼女の周囲に幾何学的な「黒い結晶体」が展開され、魔力弾を吸い込むように無力化してしまった。火花すら散らない、絶対的な拒絶。

少女の瞳が、ゆっくりと戦場の中心――泥の中で這いつくばる黒田博之を捉えた。

『――不浄なる因子の源流を検知。……あなたが、私の「檻（マスター）」ですか？』

オルゴールのように透き通り、それでいて感情を削ぎ落とした声が博之の脳内に直接響く。

「……は？ 檻だか何だか知らねえがな……」

博之は口元のヘドロを袖で拭い、全裸の少女を忌々しげに睨み返した。

「まずは服を着ろ。……見てるこっちの魔力が削れる」

『理解不能。衣服の有無と管理任務の遂行に因果関係は認められません。……それよりも』

少女の視線が、再び銃口を向ける兵士たちへと向けられた。瞳の奥で、赤黒い回路のような光が激しく明滅する。

『マスターの周辺に低級な殺意を確認。環境の清浄化――すなわち、障害の根絶を推奨します』

「おい、待て……！」

博之の制止を待たず、少女の頭上に巨大な黒い魔力の渦が形成された。それは先ほど博之が振るった「泥の刃」とは比較にならない質量。一撃放たれれば、この場の兵士はおろか、勝浦の市街地すら消し飛びかねない「終末」の予兆。

「皇様、退避をッ！」

副官が叫ぶが、スメラギは動けなかった。 彼が誇る白銀の魔力が、少女の放つ圧倒的な「圧」の前に、ただの霞のように薄れていくのを感じていたからだ。

少女が、その細い指先を軍の部隊へと向け、振り下ろそうとしたその時。

「止めろっつってんだろ、このポンコツ……ッ！」

博之が、軋む身体を無理やり動かし、少女の細い手首を掴み引き寄せた。

『……！ マスター、なぜ。この個体群はあなたに敵意を――』

「こいつらは……俺の『仕事』の道具だ。勝手に壊すんじゃねえ」

博之は少女を自分の方へ強く引き込み、周囲の視線を遮るように、自分の薄汚れた制服のジャケットを彼女の白い肩に乱暴に被せた。

少女は驚いたように、数回瞬きを繰り返した。 博之の掴んだ手首から流れ込むのは、汚泥のような不快な魔力。だが、その奥にある「檻」としての強固な意志に触れ、彼女の攻撃回路は急速に鎮静化していく。

『……了解。マスターの優先命令を受理します。……排除シーケンス、凍結』

少女の瞳から赤が消え、無機質な青へと戻る。 彼女はそのまま、自分に向けられた無数の銃口を意に介さず、博之のジャケットを不思議そうに手繰り寄せた。

博之は肩で息をしながら、包囲する兵士たち、そして愕然と立ち尽くすスメラギに挑発的な視線を向けた。

「……見た通りだ。こいつは俺の……『飼い犬』だ。軍が俺みたいなゴミに押し付けた、手に負えない獣だよ。……触りたきゃ好きにしろ。ただし、次にこいつが噛み付いた時、誰が責任を取るか……楽しみだな」

博之は、少女が自分にしか制御できないことを、その場の全員に刻みつけるように、彼女を連れて歩き出した。 その背中は、どんな「光」よりも不吉で、どんな英雄よりも残酷に、スメラギの瞳には焼き付いた。

＊＊＊

数時間後。内陸部のシェルター。 巨大な街頭スクリーンには、編集された戦闘映像が映し出されていた。

『――防人第１班・皇征弦候補生が海魔を撃退！ 犠牲者はゼロ！』

平和を享受する市民たちが歓声を上げる。 だが、その映像をモニターで見つめるスメラギの心は、泥沼の底へと沈んでいた。

斑鳩教官が、スメラギの机に博之の治療記録を叩きつける。 「いい絵だな、皇。お前はこれからも、黒田が啜った泥の上で、最高に綺麗な王子様を演じてろ。……お前の『白銀』じゃ、あのバケモノ（エリス）を止めることはできなかった。それが、お前が背負う『嘘』の重さだ」

斑鳩は影の中に消えた。 スメラギは、手の中の『白銀』を強く握りしめた。 その美しい刀身に映る自分の顔が、今はひどく空虚で、博之の啜る泥よりも汚れているように感じられてならなかった。

隔離棟、冷たいコンクリートの部屋。 博之は一人、ボロボロになった軍用ナイフの刃をぼんやりと見つめていた。

「……ま、これでいいんだ。汚い仕事には、汚い道具が相応しい」

博之は、自分でも気づかないほど、その「泥纏いの刃」を愛おしそうに撫でた。 明日、一人の幼馴染がこの部屋の扉を叩くことなど、今の彼はまだ知る由もなかった。
