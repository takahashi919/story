# 報復のツァラトゥストラ — SAKIMORI（防人）

> これは、世界を一つ殺して作られた、最高に狂ったハッピーエンド。

NotebookLM / Gemini で書いていた物語を、Claude と一緒に書き直すためのリポジトリ。

1980年（新西暦）、千葉・勝浦。海水を含んだ雨の日にだけエイリアンが上陸する。
悪魔の王の因子を宿した「泥を啜る」少年・黒田博之と、空から降ってきたデウスエクスマキナの端末・エリス。
コンクリートの監視棟で育った歪な疑似家族は、8月に理不尽に壊される。
そして世界は、エリスの手で書き換えられる。

## 構成

| パス | 中身 |
|---|---|
| `canon/` | **正史**。設定はここにしか書かない。索引は `canon/README.md` |
| `episodes/` | 本文。話ごとのフォルダに 骨組み・本文・提案・回答・調停・整合チェック |
| `harness/` | 執筆の仕組み。手順、オーナーの好み、文体、テンプレート、字数計測スクリプト |
| `.claude/` | Claude Code 用のコマンド（`/tz-*`）とサブエージェント（執筆担当・三嶋・孫の手・齊藤・整合チェック） |
| `sources/` | 最初の草案（＝第1部の土台）と正史資料。設定書・防人めも・年表2本の書き起こし（原文ママ） |
| `archive/2026-03_notebooklm/` | 3月の制作記録。作家会議ログ、第0〜8話の旧原稿、ペルソナ、旧ハーネス |
| `notes/` | 移行時のメモ（3月時点の到達点、草案の食い違い） |

## 書き方

このフォルダで Claude Code を開き、`/tz-status` で状況を見る。
1話の流れは `/tz-plan N`（骨組み）→ `/tz-write N`（本文）→ `/tz-round N`（提案 → オーナーの回答 → 調停 → 再構築）を、納得するまで繰り返す。
詳しくは `harness/手順.md`。

`sources/` の 4 本（Google Drive「素材」フォルダから salvage）:

| ファイル | 内容 |
|---|---|
| `01_キャラクター設定書_改訂版.md` | 世界設定・キャラ・プロローグ6シーン・1980年年表・4章構成案 |
| `02_防人めも.md` | 前時代〜1986年までの歴史メモ |

NotebookLM 上だけにあったもの（チャット履歴そのもの、音声概要など）は入っていない。
