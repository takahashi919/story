# 報復のツァラトゥストラ — SAKIMORI（防人）

NotebookLM で書いていた物語を、Claude と一緒に書き進めるために引っ越したリポジトリ。

1980年（新西暦）の千葉・勝浦新都市。武門の家に生まれた黒田博之のもとに、並行世界から少女エリスが落ちてくる。
防人（日本海洋警備軍）の候補生として、雨とともに現れるエイリアンと戦う一年の物語。

## 構成

| パス | 中身 |
|---|---|
| `sources/` | NotebookLM のソースとして使っていた元資料の書き起こし（原文ママ）。**ここは編集しない** |
| `notes/` | 作業メモ。設定の食い違いや決定事項 |

`sources/` の 4 本:

| ファイル | 元ファイル (Google Drive「素材」フォルダ) | 内容 |
|---|---|---|
| `01_キャラクター設定書_改訂版.md` | 報復のツァラトゥストラ_キャラクター設定書_改訂版.docx | 世界設定・キャラ・プロローグ6シーン・1980年年表・4章構成案・整合性チェック。**いちばん新しい正本** |
| `02_防人めも.md` | 防人めも.docx | 前時代〜1986年までの歴史メモ（シリーズ前提資料） |
| `03_1980年以降年表.md` | 1980年以降年表形式.docx | 1980年の詳細年表（設定書の年表より描写が細かい） |
| `04_新規案年表_前時代.md` | 新規案年表.xlsx | 3020年〜1853年の前時代史（神聖十字軍・終末教団・モルトケ・魔力の起源） |

資料同士で食い違う点は [`notes/整合性メモ.md`](notes/整合性メモ.md) にまとめてある。

## salvage について

- NotebookLM のノート本体（`notebook.google.com/...`）はログインが必要で外から読めないため、ソースとして入れていた
  Google Drive 上の元ファイルから書き起こした。
- NotebookLM 上でだけ書いたもの（チャット履歴、保存したノート、音声概要など）はここに入っていない。
  残したいものがあれば、NotebookLM からコピーして `sources/` に足す。
- 設定書の docx にはコメントが付いているが、書き起こしには含まれていない（元ファイルで確認できる）。
- Drive の「小説パート」フォルダは空だった。
