# 執筆の手順

オーナーの好みと作家ペルソナを元に骨組みを決め、本文を出し、
三嶋・孫の手が展開を提案し、オーナーが採否と自案を答え、齊藤が調停して再構築する。これを繰り返す。

```
 /tz-plan N ──▶ 骨組み.md ──オーナー承認──┐
                                          ▼
 /tz-write N ─▶ 執筆担当が 本文.md を書く ─▶ 整合チェック ─▶ 整合.md
                                          │
          ┌───────────────────────────────┘
          ▼
 /tz-round N   ① 三嶋・孫の手が 本文 を読んで展開を提案 ─▶ 提案_rK.md
   （1ラウンド） ② オーナーが採用・不採用・自案を答える    ─▶ 回答_rK.md
                ③ 齊藤が調停し、再構築の方針を出す      ─▶ 調停_rK.md
                ④ 執筆担当が本文を再構築               ─▶ 本文.md（旧版は 履歴/）
                ⑤ 整合チェック、決まったことを canon へ ─▶ 整合.md、canon/決定ログ.md
          │
          └─▶ 納得するまで /tz-round N を繰り返す ─▶ オーナーが「確定」
```

## 道具

| コマンド | すること |
|---|---|
| `/tz-status` | 進行表と未決事項を見る。次に何をするか提案する |
| `/tz-plan N` | 第N話の骨組みを組んで、オーナーの承認をもらう |
| `/tz-write N` | 骨組みから本文を書く（初稿） |
| `/tz-round N` | 提案 → 回答 → 調停 → 再構築 → 整合 の1ラウンド。途中で止めても、次に呼べば続きから再開する |
| `/tz-check N` | 整合チェックだけ行う |
| `/tz-decide 内容` | チャットで決まったことを canon と決定ログに書く |

| サブエージェント（`.claude/agents/`） | 役割 |
|---|---|
| `tz-writer` | 執筆担当。骨組み・調停方針・canon・文体に従って本文を書く。ペルソナなし |
| `tz-mishima` | 三嶋与夢の視点で展開を提案する（偽悪、意図と結果の乖離、認知負荷、テンポ） |
| `tz-magonote` | 理不尽な孫の手の視点で展開を提案する（苦難、余白、五感、失敗とリカバリー） |
| `tz-saito` | 齊藤陽介の視点で調停する。足して2で割らない。尖りは残し、外装を整える |
| `tz-continuity` | 整合チェック。canon・前の話・オーナーの好みと照合して、矛盾と新設定を洗い出す |

ペルソナの定義の元は `archive/2026-03_notebooklm/personas/`。3月の会議の口癖や温度感は残しつつ、出力は「オーナーが選べる形」に絞っている（`オーナーの好み.md` 18）。

## ファイルの置き場所

```
episodes/第0部/
  進行表.md                  各話の状態（骨組み/初稿/rK/確定）と字数
  00_泥雨の異端者/
    骨組み.md                この話の設計図（プロット＋行動意図）。承認後も調停で更新される
    本文.md                  最新の本文
    履歴/本文_r0.md          初稿。/tz-round のたびに直前の版をここへ退避
    提案_r1.md  回答_r1.md  調停_r1.md
    整合.md                  最新の整合チェック結果
```

テンプレートは `harness/templates/`。

## 約束

- **canon が先、本文が後。** 本文で生まれた新しい設定は、調停で採用され、`canon/` に書かれるまでは正史ではない（`/tz-round` の⑤、`/tz-decide`）。
- **未決には勝手に答えない。** 骨組みや本文が canon の「未決」に触れる時は、触れずに済む書き方をするか、オーナーに聞く。
- **字数は測る。** `harness/tools/measure.py`。
- **天気は引く。** `harness/tools/weather.py`（勝浦の1980〜1982年の実測）。
- **旧原稿は素材。** `archive/…/drafts/` は書き直しの参考にしてよいが、canon と食い違う箇所（`notes/第0部_現状.md` §3）はそのまま持ち込まない。
