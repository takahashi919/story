# 第0部 通し骨組み パターン③ 統合設計書(齊藤陽介)

（設計担当 tz-saito の出力）

**方針**: 足して2で割らない。落とし方は①の階段、請求書の書き方は②の嘘の利息。結末は「勝手にしろ」で署名させて、「待て」を破らせる。両案の一番痛いところは全部残した。そのかわり話数は21で打ち止め。同じ働きの小道具(砥石と缶)は1つに絞る。成功したら作家の手柄、失敗したら俺の責任だよ。

記法: ①=三嶋案、②=孫の手案。「①A3」=①part_A第3話の同名シーン。天気は `data/気象` 原本で照合済み(執筆前に weather.py で再確認のこと)。

## 2. 全体アークと核の尖り

- **幕I 泡沫 0–8(5/4–5/17)**: 疑似家族の完成。偽悪と共犯、味覚の予兆。
- **幕II 腐食 9–14(5/22–7/31)**: 請求書を日常の小道具で配る。13話が頂点(不穏なし)、14話で落とす。
- **幕III 請求 15–20**: 破局は15–18(8/1–8/3、1日1打)、断層は19–20。

核の尖り
1. 全員が博之を守るためにつく嘘が、1日1打で請求される。階段で落とし、利息で因果を縛る。
2. 躾の言葉が世界を殺す。「勝手にしろ」で許可し、「待て」で撤回する。エリスは生涯一度の不服従をして、最後の行は「待ては、できませんでした」。
3. 永劫は物で数える。唐揚げ6個、ジャケット、ナイフ、砥石。最後の「美味い」の嘘が引き金。

偽の安全(①維持): 「死ぬなよ」を言われるのは博之で、死ぬのは言った側/陽子の転属は8話で撃退済み/13話に不穏なし(斑鳩の「あと2回だ」は16話へ移す)。
