## 要修正（矛盾。根拠付き）

1. **第2話（5/7）の斑鳩の台詞が、まだ来ていない雨の日を過去形で言っている**
   - 引用：「五日と八日と九日の雨は、他班が受けた。お前たちは、そのあいだ手を出すな」
   - 根拠：場面は 5/7（水）。weather.py で 5/8・5/9 は 5/7 の翌日以降。part_A 冒頭の変更点5も「5/5・5/8・5/9 の雨は他班が受けた」と過去形で書いている。直前の「出撃許可は、今日の結果で下りる」とも噛み合わない。
   - 直し方：「五日の雨は他班が受けた。八日と九日の雨も、お前たちは手を出すな」。または出撃停止を「評価が出るまで」と言い、日付を列挙しない。
2. **第0話の夕方の報道と、第1話の「映像は皇の分だけ編集して流しなさい」の時系列が逆**
   - 引用（ep0）：「基地の広報室。壁際のテレビが、内陸向けの夕方のニュースを繰り返している。」「画面の中の自分は、雨の中でも泥一つつけずに微笑んでいた。」
   - 引用（ep1）：「映像は、皇少年の分だけ編集して内陸に流しなさい」（5/5 午前2時40分、同時刻の成瀬の指示）
   - 根拠：編集して流す指示が出る前に、5/4 夕方にもう放送されている。canon 話数表は報道を ep0（報道と斑鳩の一言）にも ep1（成瀬初登場）にも置いているので、同じ報道なら時刻を揃える必要がある。
   - 直し方：ep1 の台詞を「続報」「明朝の広報用の再編集」に変える。または ep0 の夕方の放送を撮影班の速報とし、成瀬の指示は「博之の映像は流すな／皇の分を差し替えよ」とする。
3. **第4話の夜の場面が雨音を持っている（5/10 夜は降水なし）**
   - 引用：「コンクリートの壁が、雨の音を全部吸い込んでいた。」（陽子の縫合・首輪宣言の場面の末尾）
   - 根拠：weather.py 1980-05-10 夜：降水なし。part_A の第4話冒頭の注記も「夜は雨を降らせず、雨の名残の冷え」と決めている。窓のない地下で雨音が聞こえる描写でもある。
   - 直し方：「換気ダクトの低い音が、部屋の音を全部吸い込んでいた」のように、雨に頼らない。
4. **第5話のジャケットの洗濯が、冒頭の注記と本文で食い違う**
   - 引用（位置づけ）：「ジャケットは、今日、初めて洗濯されて乾く。」
   - 引用（本文）：「陽子が昨日洗ったやつだ。泥と血が全部取れて」
   - 根拠：洗ったのは 5/10 夜なら「昨日」、5/11 当日なら「今日」。5/10 夜の第4話に洗濯の描写はなく、エリスは第3話で雨に濡れたままの描写。
   - 直し方：注記を「昨日（5/10 夜）に初めて洗濯された」に直す。または第4話の終わりに洗濯物の一行を足す。
5. **第3話のカレンダーの丸の数え方**
   - 引用：「壁のカレンダーに丸が4つ増えたことを、博之は初めて数える」（位置づけ・構成にも「丸が4つ（5/4・5/5・5/8・5/9）」）
   - 根拠：ep1 で 5/4・5/5 の丸はすでに付いている。増えたのは 5/8・5/9 の2つ。
   - 直し方：「丸が4つになったことを」。
6. **ナイフの欠けの位置が part_B と食い違う（継ぎ目）**
   - part_A：「峰に近いところ、切っ先から指二本ぶん。米粒ほどの欠け」（ep0、ep4、ep5、ep6、ep8 で一貫）
   - part_B ep10：「欠けは、五月からそこにあった。鍔の近く、左の縁、指の幅くらいの小さな欠け。」
   - 根拠：F5 は物語を通した時計なので、場所の食い違いは致命的。part_A 側を正にするなら、part_B ep10 を直す。
   - 直し方：part_B ep10 を「切っ先から指二本ぶん、峰に近い所」に合わせる。
7. **末尾の台帳表の記載が本文と合っていない**

8. **第7話の観測ログ「マスターの会議中」**

   - 直し方：「マスターに関する会議中」、または会議の語を使わず「本機は待機」。

3. **雨の日に二人が出ない日を作ること**

- **好み1（語らせない）：第6話「綺麗だな、と思った。思って、すぐに頭から追い出した。」**

- **好み2（説明しない）：第6話の動機の計算（「寸止めは、駄目だ。…一度で済ませる。済ませる方法は、一つだけ。」）**

- **視点の印の欠け**
  - ep3「朝の唐揚げと分析」、ep5「圧縮されたシャツ」、ep7「大雨のあとの白石」の3つの非★は `<!-- 視点: -->` がない。ep7 の白石は「博之が一人称で…（博之は…おかしいと思う）」と一人称と三人称が混ざっている。ep3 と ep5 は時制も現在形の梗概。

- **好み3（物質）**：総じて良い。ベルト、蓋の反り、タッパー、欠け、歯形の輪、ジャケットなど、物で見せている。

## 継ぎ目の問題

- **5/10 → 5/11 → 5/15 の傷**：5/10 の左前腕の縫合（17針）が、ep5（腕を通す、ナイフの分解）、ep6（左肩の傷）、ep8（砥石）で一度も出ない。ep6 は左肩を斬られる。ep6〜ep8 の左肩の怪我（320ml）も、ep7（辞令を受け取る）、ep8（缶コーヒーを投げ、砥石を使う）で触れられていない。part_B ep9（5/26）は出撃で動く。

## 強み／弱み

強み
1. **F8（ep3 三人称の陽子 → ep4 一人称の博之）**：読者だけが「陽子は歯形を見た」と知った状態で、博之の「転んだだけ」を読ませる構図。針が穴を避ける縫い方、蓋の反りを爪で押さえる動作など、物だけで感情を運んでいる（好み1・3）。
2. **F5 欠けの時計**：ep0（米粒の欠け）→ ep4（斑鳩「研いで消すな」）→ ep5（増えていない）→ ep6（親指に引っかかる）→ ep8（研ぎすぎで縁が広がる）。位置が固定されていて、博之が自分で負債を積む。ep8 は「気づかなかったことにした」で止めている。
3. **F12／F4（ep8）**：「名前では、呼ばなかった」で締め、87% の否定で憧れを一語も言わせない。ep0 の刀筋の細密な描写から ep6 の至近距離、ep8 へ線が続いている。F18 の「拒否は実行不能、保留は受理」も、2行で ep21 の不服従を仕込んでいる。

弱み
1. **箱庭の請求が薄い（ep5、ep7、ep8）**：設計書は「博之は毎回自分で傷を選び、その負債が請求されない」を問題にしているのに、第1幕の負債は歯形と欠けが中心。味覚の兆候は ep8 の一行（味が遅れる）、ep1 の指の震えだけで、ep5〜ep8 は日常の描写が優勢。ep9 以降の請求への助走としては静か。
2. **F2 と F10 の空白（ep1〜ep11）**：手負い残しは ep0 で立てた後、ep12 まで再掲がなく、台帳表だけ「ep6 再掲」と書いている。斑鳩の震えも ep2 の一行だけで、ep6・ep7 の斑鳩の場面（右腕を発熱させる、拳を隠す）に重ねる機会を使っていない。
3. **非★の薄さと連続性の細部**：ep3 の朝、ep5 の圧縮、ep7 の白石は梗概のみで視点の印がなく、本文粒度の比較ができない。傷（左前腕、左肩）、5/13 の点→丸、ジャケットの洗濯が、話をまたぐと拾われない。
