# 第0部 全体設計 パターン②(理不尽な孫の手案)「嘘の利息」

（設計担当 tz-magonote の出力。日付は仮。執筆担当が weather.py で実測照合して雨の日にずらす）

話数表の0〜8話は「楽園の下書き」として優秀だが、苦難が足りない。博之は毎回自分で傷を選んでいるのに、その負債が一度も請求されない。この設計では、**8/3 の破局を、誰かの悪意ではなく全員の優しい嘘の利息**にする。

## 1. 全体アーク
全22話(0〜21)。
- **第1幕「泥と箱庭」0〜8話(5/4〜5/17)**：話数表どおり。全員が嘘をひとつずつ持つ。博之は偽悪、陽子は見ないふり、スメラギは光、斑鳩は冷たい顔、エリスは嘘をまだつけない。
- **第2幕「摩耗と利息」9〜15話(5/26〜8/2)**：ヤマトの誘い、規律違反、移植、白石の死、録音、地下の祭り。読者を油断させながら、請求書を積む。
- **第3幕「請求」16〜21話(8/3〜永劫〜リライト)**：陽子のロスト、斑鳩の死、エリスの涙、スメラギの盾。永劫の闘い2話、リライト1話。

**核となる尖り(3行)**
1. 破局は嘘の総額である。博之の偽悪、陽子の「大丈夫」、エリスの隠匿、スメラギの光、成瀬の編集録音、最後にはエリスの「陽子は生きています」と世界のリライトまで、全員が守るためにつく嘘を積み、8/3 に一度に請求される。
2. 「待て」「よし」という躾を、最後にエリスが破る。ep0 の「飼い犬」から ep3 の「待て／よし」を経て、リライトは愛の爆発ではなく、彼女が生涯で一度だけした不服従になる。最終行は「待ては、できませんでした」。
3. 永劫は物の時計で見せる。エリスが胸で温め続けるタッパーの唐揚げ6個(100日・1年・10年・100年・1000年・1万年で1個ずつ食べる)、擦り切れるジャケット、折れるナイフ、ドロップ缶の音。最後の1個で博之が言う「美味い」の嘘が、リライトの引き金になる。

余白に置くもの(説明しない)：①エリスが陽子を妹にした理由(ログの空欄だけで見せる) ②博之は陽子の死を知らない ③成瀬の私怨の根 ④スメラギの名前を誰も言えなくなる理由。

## 4. 結末の詳細設計

### 4-1. 8/3 は負債の返済である(必然の積み重ね)
- ep0 の手負い残しは ep12 で白石を殺す。そこから全滅方針に変え、摩耗が倍になる。
- ep3 の「待て」だけが、博之がエリスを繋ぐ綱になる。その綱が ep17 で切れる。
- ep3 の「転んだだけ」で、陽子は「見ない」を覚える。それを成瀬の録音に使う。
- ep7 の生贄特進(独断体制)があるから、ep18 で軍は躊躇なく撃てる。
- 陽子が去る件を皆が黙ったことで、博之は 8/3 に1人で知り、あの失言を口にする。

### 4-2. 誰が何を知るか
- **博之**：陽子の出発(8/3 朝に初めて)。陽子の死は知らない。リライトも知らない(ep20 のときは眠り際)。
- **エリス**：全部を知る。陽子の死亡(永劫の41日目に座標消失)を博之に隠す。
- **軍・成瀬・東雲**：エリスが友軍を撃ったので、敵性と認定する。これは本人たちにとって筋が通る。
- **スメラギ**：消える直前に博之の本物の姿を最後に見る。

### 4-3. 永劫の描き方
- **場**：灰色の空と、足首まで固まった黒い泥の床。雨は降らず、光源はなく、数万の声が遠くで鳴る。外見は変わらず、衣服と傷だけが進む。
- **ルール**：巨大個体は床から再生する。エリスは討伐のたびに侵略許可の断片を回収する(これが生贄の中身)。博之には「出口を探している」としか言わない。
- **文体**：博之の一人称は名詞の断片に痩せていく。エリスの経過ログ(日数)が主な語り手になる。
- **時計**：ジャケット、ドロップ缶の音、タッパー。エリスは胸で温めて保存し、そのコストを自分の出力から毎日払う。唐揚げの1個ずつが10倍刻みの節目になる。

### 4-4. エリスの内側の変化(感情語を使わずに)
熱反応(ep5)→ 恐怖と吐き気(ep11)→ 嘘(ep13)→ 願い(ep14：ログを消したくない)→ 涙(ep17)→ 憎しみと私情(ep18)→ 独占(永劫)→ 手放し(ep21)。永劫でエリスは檻の側になる。元は博之が「檻(マスター)」で彼女が獣だった。合図を出すのが彼女に移り、彼は従う側になる。リライトはその檻を、彼女自身が壊す行為になる。

### 4-5. リライトの流れ(ep20 の終わりから ep21)
1. 最後の1個。博之が「美味い」と笑う。同期でエリスに血の味だけが流れ込む。
2. エリス「合図を」。博之(半分眠り)「…まだだ。待て」。エリス「了解」。
3. 編集は10年かけて探した最小の罪から始まる。ログは次の形に絞る(地の文は足さない)。
