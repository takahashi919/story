## 要修正(矛盾。根拠付き・引用付き)

1. **16話で博之が「エリス」と呼んでいる(F5違反)**
   - 本文: 16話「降雪」冒頭近く、`「エリス」` → `【気温、摂氏4度。降雪、確認。季節外れです】`
   - 根拠: 設計書 F5「博之はエリスの名を呼ばない…20話で初めて呼ぶ」。part_C 15話の解説「『エリス』と一度も言わない」、18話の `「エリス」と言いそうになって、飲み込んだ。`、20話の `「……今、何と」「二度は言わねえ」` はすべて「呼んだことがない」前提。
   - 直し方: `「おい」`、または呼びかけなしで `見りゃ分かる`。17話の `離せ、ポンコツ` と揃える。

2. **17話で名前を言ってしまった直後に「飲み込んだ」と書いている(行内の矛盾+F5)**
   - 本文: 17話「手首を掴まれる」`「離せ、エリス——」` / `言いかけて、名前を飲み込んだ。名前の形が、口の中でまだ硬かった。`
   - 根拠: 台詞に名前が出ているので「飲み込んだ」と合わない。F5(18話の呼びかけて飲み込む、と同型)。
   - 直し方: 台詞を `「離せ、——」` にして、名前を口にしない形にする。

3. **20話の博之が「四話」と言っている(作中人物がメタ参照)**
   - 本文: 20話「許可」`三十年。いや、三十年と少し。俺がエリスの口を塞いだのは何度目だろう。四話の夜から、何度。`
   - 根拠: 「話数」は作品の外の単位。一人称の世界の中で博之が知り得ない(一人称の破れ)。
   - 直し方: `あの雨の夜の台所から、何度` のように作中の出来事で指す。ただし canon の「四話の夜」は5/10夕〜夜の監視棟(肉じゃが・「転んだだけ」でエリスの口を塞ぐ)なので、場所を台所に揃える。

4. **15話の最終ラベルとタッパーの数が合わない(数字の食い違い)**
   - 本文: 15話「朝・タッパー10個」`『8/2 昼』。次が『8/2 夜』。『8/3 朝』。端まで数えて、最後のテープは『8/11 夜』だった。` / `誰が十日分も食うんだ。`
   - 根拠: 昼→夜→朝の並びは1日3食。10個なら最後は8/5昼で、8/11夜にならない。16話は9個から『8/2 夜』を取っていて、10個前提。B側15話のラベルは最後が『8/6 夜』(part_B 15話)。
   - 直し方: 最後のラベルを8/5昼にするか、1日1個にして最後を8/11にするか(「十日分」はこちら)。ラベルの並びの書き方もそれに合わせる。B版との統一も要る(継ぎ目参照)。

5. **17話の観測ログの睡眠・摂食が、15・16話と食い違う**
   - 本文: 17話ログ `・睡眠：0時間（連続36時間）。摂食：1回（8/2 夜）`
   - 根拠: 15話 `マスターは睡眠に入りました`(8/1 21:00)、`五時二十分に目が覚めた`(8/2)。8/3 06:31から36時間さかのぼると8/1 18:31になり、睡眠を挟んでいる。実際は8/2 05:20起床から約25時間。16話 `一個は、朝にレンジで温めて食った` で8/2は朝・夜の2食。
   - 直し方: `連続25時間`、`摂食：2回（8/2 朝・夜)` に。

6. **18話「忘却」で、見ていないはずの写真の中身を語っている(一人称の破れ)**
   - 本文: `写真は、見なかった。兵の顔を見ていた。写真の中の白い軍服の男に、誰も指を向けなかった。`
   - 根拠: 設計書 F21「博之が見るのは写真ではなく兵の忘却」。「見なかった」と書いた直後に、写真の中の男(と誰も指を向けないこと)を語っている。
   - 直し方: 末尾の1文を、兵が写真から目を上げて写真をポケットに戻す、など博之に見える動作に置き換える。

7. **18話の集合写真が、13話と合わない**
   - 本文: 18話 `胸ポケットから、折れた写真を出した奴がいた。明け祭ごっこの、集合写真だった。皆、同じものを持っていた。` / `「十二人だろ」「……十三人じゃなかったか」`
   - 根拠: part_B 13話 `一枚きりの写真は、来週、現像に出すことになった。`(複数枚の配布なし)。写っているのは通信班・新兵・白石・スメラギ・エリス・博之・陽子・斑鳩で、13人を超える。しかも8/3時点で白石は死亡、陽子は消失しているので、兵が数える人数が「13」になる根拠がない。
   - 直し方: 13話側に「焼き増しして配る」を足す(13話担当との調整)か、18話を「兵のうち一人が持つ1枚」にする。人数の台詞は、写真の人数を数えさせずに「写真の真ん中だけ空いている」に変える案がある。

8. **15話の録音が、14話(B)の録音と食い違う(前話との矛盾)**
   - 本文(C): 15話「録音」`『要請は受理していない。待機』` を `湿った丁寧語` で答え(=成瀬の声)、続いて `『……誰が止めた。撤退を止めた奴は。聞いてんだろ、本部。出てこい。出てきたら、俺が』` `『殺してやる』` という博之の声が入っている。冒頭まとめでは「白石の死後、通信機が生きたまま拾った」。
   - 根拠(B): 14話では、撤退要請に答えたのは `本部当直の声。『撤退要請を受信。上申中。――保留』`(成瀬ではない)。博之が着いた時 `壕はもうなかった`、白石は救護所で陽子の腕の中で死亡。博之は要請が握りつぶされたことを知らない(陽子は `ずっと、謝ってた` と嘘をつき、博之は `聞かなかった`)。博之が `誰が止めた` と言う動機がなく、壕に拾われる場もない。成瀬は要請部分を `切り落とした帯は、くるりと丸まって、灰皿に落ちた`(捨てた)。15話Cは9時にその部分を再生している。
   - 直し方の候補: (a) 殺害予告を「本部への無線で博之が怒鳴った一言」とし、14話に1行足す。(b) 殺害予告を外し、脅しの材料を「撤退要請を握りつぶした成瀬自身の声の保管」と、白石の遺言の編集に絞る(18話の「上官への殺害予告」の件は作り直し)。(c) 声の主を `本部当直` に戻す。いずれにせよ14話担当との調整が要る。

9. **15話で、エリスは父の「続き」を聞いていない(19話の再生が成立しない)**
   - 本文: 15話「面倒を見られるのはあんたしかいない」は、父の台詞全文が陽子の回想(地の文)として出る。陽子の発話は `あれ、続きがあったの` まで。
   - 19話: `お父様の発言には、続きがあります。陽子から、聞いています` → `再生します` と、エリスが全文を声色つきで再生する。
   - 根拠: 15話の台詞の上では、エリスは続きの中身を陽子から聞いていない。
   - 直し方: 15話に、陽子が口に出して伝える台詞を1〜2行足す(全文でなくてよい。19話で全文が出る事実とつなぐ)。

10. **20話のログで、スメラギの「抹消」が読者にも読み取れない(誰が何を知っているか表が成立しない)**
    - 本文: 20話「保留」`皇征弦　　　　　　　　　　　　　処理：実行　　理由：入力なし`。19話「願い」では `最大化対象＝以下の固有名詞が存在する状態　陽子／斑鳩／白石／皇征弦／（欠損）`。
    - 根拠: part_C 冒頭の厳守表「スメラギの抹消: 読者は知っている(20話のログで抹消が実行されるのを読者だけが見る)」。19話で皇征弦が「存在する状態」の側に載っているので、`処理：実行` は「存在させる」と読める。抹消を示す語が20話のログのどこにもない。
    - 直し方: 処理欄に語を入れる(例: `処理：抹消(生起履歴の除去)`)。「理由：入力なし」は残してよい(動機を断定しない)。

## 要決定(canon に答えがない、または未決に触れている。オーナーに聞く)

1. **斑鳩・白石は新世界に存在するか(未決。`人物/斑鳩巌.md`「第1部に存在するかは未決」)**
   - 20話「許可」でエリスが `陽子のいる世界です。斑鳩のいる世界です。白石のいる世界です。` と博之に約束している。一方で同話のログは `斑鳩巌／白石　処理：実行時に確定` で、part_C 自身の「未決に触れない」方針と食い違う。本文を直すか、答え(存在する/しない)を決めるか。
2. **日付の移動と、第0部のヤマトの扱い**
   - 設計は破局を8/5→8/2〜8/3に前倒し(`年表/第0部_1980.md` は仮案で8/5。矛盾ではない)。18話は、canon で「第0部での扱いは未決」の試作ヤマトを、貨物線上の砲身・試験場跡の機体を持ち込む設定として出している。次元断層が第1部8/5の断層と同一か(設計§6-2)も未決のまま。
3. **皇家宝刀『白銀・征弦』の行方(設計§6-9、未決)**
   - 19話の刀は銘を出さない処理だが、18話でスメラギが抜いた刀の直後、断層に立つ刀として読者は征弦の刀と読む。「銘を出さない」で未決を避けたことにならない。決めるか、刀の出自を別にするか。
4. **断層内の時間・食事(設計§6-11、未決)**
   - 11,013日、`三十年と少し` の記述。19話は老化を書かないが、唐揚げの材料(随行の殻下脂肪・澱粉相当の組織・割れた盾の皿)で「食事」に答えが出ている。それまで何を食べたかは書かれていない。
5. **観測ログの第1部続行(未決)**
   - 20話最終ログ `【観測ログ 1980/05/03 05:48　対象：（空欄）】` `位置：勝浦・黒田道場分邸 上空` `状態：落下中`。第1部で落下する日時・場所を確定させ、ログが続く前提を置いている。`照度：9.7時間相当（予報値）` は日照時間の実測であり「予報値」と書く根拠がない。
6. **階級名「一等兵」(未決。`世界/防人と軍.md`「階級の正式名称は未決」)**
   - 15話「録音」`白石一等兵の件です`、18話「命令」`白石一等兵の死に際`。canon は「通信兵(新兵)」まで。
7. **父の「続き」の場面の設定**
   - canon は「言った直後、父は誤解させたことを悟って取り繕う。だが博之はショックで聞いていない」。part_C は、博之が走り去った後、`靴も履かずに戸口まで出た。誰もいない庭に向かって` 独り言を言い、聞いたのは陽子だけ、という新設。canon と矛盾はないが、父の発話の全文は新設(陽子の回想で語る、という canon の範囲内)。この場面の置き方と台詞の全文を canon 化してよいか。
8. **ナイフ「使えて一度」→ 約2,400日の使用、破片の行方(好み5・ご都合防止)**
   - 17話の斑鳩 `使えて、一度だ`。19話は `何千回使ったか`。理屈は解説にしか書かれておらず本文にない。ナイフ砕け(2,418日)から刀(4,690日)までの約2,270日の武器も不明。20話の `N1(破片は第1部の箱へ。案)` は本文に出ていない。
9. **18話の「兵の忘却」と20話の「抹消」の二重化**
   - 18話でスメラギが燃えた時点で兵が彼を忘れる(博之は覚えている)。20話ログの `皇征弦　処理：実行` は、その延長か、別の消去か。博之は18話で兵の忘却を見ているので、厳守表の「博之は抹消を知らない」と、どこまで合わせるか。
10. **成瀬の結末(設計§6-7)が20話にない**
    - 20話の差分適用先に成瀬・東雲がいない。18話で成瀬が無傷のまま終わるので、新世界の成瀬を第2部の火種にするかどうかが空欄。
