# 2026年3月 NotebookLM / Gemini 期の制作記録

草案（`sources/`）を「読まれる文章」にするために試行錯誤した来歴と成果物。
三嶋与夢・理不尽な孫の手の作家性を持たせたペルソナが尖った案を出し、齊藤陽介ペルソナが調停する。
その会議でプロットを固め、第0部（世界改変前）の第0〜8話を書いた。

到達点と、本文が決定に追いついていない箇所は [`notes/第0部_現状.md`](../../notes/第0部_現状.md) にまとめてある。

| フォルダ | 中身 |
|---|---|
| `drafts/` | 第0〜8話の本文。第0話は3稿（`00a` 初稿 → `00b` 第2稿 → `00c` MTG4 の最終稿を組み立てたもの） |
| `mtg/` | 作家会議のログ 0〜5。オーナーの指示は【オーナー】行 |
| `summaries/` | 完全版ストーリーライン、第0部の各話まとめ |
| `personas/` | 三嶋与夢・理不尽な孫の手・齊藤陽介のペルソナ定義 |
| `old_harness/` | 3月に用意した Claude Code 用の旧設定（使わなかったもの） |

## 手を入れた点

- 改行を CRLF → LF にし、行末の空白を削った以外は原文ママ。ファイル名は話数順に並ぶよう付け直した。
- `old_harness/旧CLAUDE.md.txt` は元は `CLAUDE.md`。Claude Code はサブフォルダの `CLAUDE.md` も自動で読み込むので、
  旧設定が今の作業に混ざらないよう名前を変えた。

## 入れていないもの

- `【参考文章】三嶋与夢①②` / `【参考文章】理不尽な語の手`：市販・連載作品の本文（計約 1.7MB）。
  他人の著作物を GitHub に上げることになるので、リポジトリには含めない。手元の zip に残っている。
- `【資料】` の3ファイル：`sources/01〜03` と同じ内容。
- `新規案年表.xlsx - シート1.pdf`：`sources/04` と同じ内容の PDF。
