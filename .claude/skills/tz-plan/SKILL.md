# 第N話の骨組みを組む

引数：$ARGUMENTS（話数。なければ `episodes/第0部/進行表.md` で次に骨組みが必要な話を選び、確認してから進める）

## 1. 材料を読む

- `canon/構成/第0部_話数表.md` の該当行、`canon/年表/第0部_1980.md` の日付。天気は `python3 harness/tools/weather.py <日付>` で実際の勝浦の天気を引く（骨組みのシーンの天気・時間帯はこれに合わせる）
- 登場人物の `canon/人物/*.md`、関係する `canon/世界/*.md`
- `harness/オーナーの好み.md`、`harness/手順.md`
- 前の話の `骨組み.md` と `本文.md`（あれば）。次の話の骨組み（あれば）
- 旧原稿（`archive/2026-03_notebooklm/drafts/` の該当話）と、関係する会議ログ。オーナー発言（【オーナー】行）は決定として扱う

## 2. 作家に一言ずつ聞く（並列）

`tz-mishima` と `tz-magonote` を **同時に** 呼び、話数表の要点と、自分が組もうとしている骨組みの方向を渡して「骨組みへの意見」を求める（各2〜3行×3項目）。

## 3. 骨組みを書く

- `harness/templates/骨組み.md` の形で、話のフォルダ `episodes/第0部/NN_タイトル/骨組み.md` に保存する（NN は2桁。フォルダがなければ作る）。状態は「案」。
- 作家の意見は、採ったものだけを反映する。採らなかった理由は1行ずつ、オーナーへの報告に添える。
- canon の未決に触れる場面は「4. 触れないこと」に挙げ、書き方で避ける。避けられない時は、オーナーに聞く項目にする。
- 骨組みは三人称の客観で書き、シーンごとに視点（一人称／三人称の視点人物／観測ログ）と「博之が知ること・思い込むこと」「読者だけが知ること」を埋める。博之が見られないが読者に見せたいものは、三人称の裏舞台か観測ログのシーンにする。視点の配分は前の話の実測（measure.py の「視点の配分」）を見て決める（`harness/文体/本作の文体.md`「視点」）。

## 4. オーナーに見せる

- 骨組みの要点（シーン構成を各1行と視点、視点の配分、引き、観測ログの有無）と、オーナーに決めてほしいこと（あれば最大3つ）を見せる。
- 選択肢のある問いは AskUserQuestion で聞く（4つ以上あれば HTML の判断シート。`harness/手順.md`「オーナーへの見せ方」）。骨組みを読んでもらう時は PDF。
- 承認されたら、`骨組み.md` の状態を「オーナー承認（日付）」にし、`episodes/第0部/進行表.md` を「骨組み承認」に更新する。
- 骨組みの中で新しく決まった設定は `/tz-decide` と同じ手順で canon に書く。

次の一手として `/tz-write N` を案内する。
