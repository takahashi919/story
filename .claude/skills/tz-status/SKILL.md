# 進み具合を見る

1. `episodes/第0部/進行表.md` を読む。各話フォルダの実際のファイル（`骨組み.md`、`本文.md`、`提案_rK.md`、`回答_rK.md`、`調停_rK.md`、`整合.md`）と照らして、進行表がずれていたら直す。
2. `canon/決定ログ.md` の「未決」と、各話の `整合.md` の「要決定」を集める。
3. 次の形で短く報告する。

```
■ 第0部
話 | タイトル | 状態 | 字数 | 次の一手
...

■ オーナーに決めてほしいこと（多い順に最大5つ）
- …（どの話の作業が止まるか）

■ 次のおすすめ
（例：「第0話は r1 の回答待ち。/tz-round 0 で再開」）
```

状態の読み方は `harness/手順.md`。何も書き換えない（進行表のずれの修正を除く）。
