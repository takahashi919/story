# 相互レビュー：理不尽な孫の手 → 三嶋案（パターン①）

> 読んだ範囲（本人申告）：設計書と part_C（第15〜20話）は通読。part_B は第11〜14話のシーン構成、part_A は見出しのみ。**第0〜8話の評価は設計書の記述に基づく**（本文は未読）。

## 1. 総評

階段で落とす構造は効いている。「部品を日常で配って、8月に意味を裏返す」やり方は、私の案にはない強さで、ここは盗みたい。
一方で、足りないものが3つある。
1. 苦難の「量」は十分だが、読者が追うべき因果の「線」が太くない。陽子の喪失、成瀬、東雲がそこで、オーナーの混乱もここに集中している。
2. 設計の都合で人が死ぬ場面が目立つ。新兵と、18話の東雲が該当する。
3. 19〜20話は論理を詰めすぎて余白が少ない。ログが全部答えを出している。

5連打自体は逃げていない。ただし13話と20話の間で、傷つけた後のフォローがほぼ丸ごと抜けている。

## 3. 捨てるには惜しい部品(トップ7)

1. **F25「勝手にしろ」の反転(15→20話)**: 偽悪の口癖が世界を殺す署名になる。盗みたい最上位。
2. **タッパー10個と日付の蓋(15話)**: 愛情を物の数で見せる。台詞が要らない。
3. **N1「袖」の連鎖(6→14→16→19話)**: 拭く行為が白石、陽子、エリスへと渡る。物でつながっている。
4. **砥石の「お前の分は彫らねえ」(17話)**: 別れの言葉を言わせない。効いている。
5. **「許可を求めます」→「好きにして」の予行(15話)と、20話での反転**: 予行がある分、反転が刺さる。
6. **対の嘔吐と、嘘を回路で見抜く唐揚げ(19話)**: 痛みを半分ずつ負う構造が、共依存の絵としてよく出来ている。
7. **靴14足と湯気の立つ飯(16話)**: 死体なしの喪失。余白の作りがうまい。

## 4. オーナー指摘への応答

- **数える癖の頻度**: 3箇所に絞る。4話で初出、12話で砥石の名前を「数えない」、19話で日数を数えるのはエリスとし、博之はやめる。それ以外は削る。
- **粒の4つ目トリガー**: 本文に粒数を出さない。見えるのは色、量、音(「いつもより黒い」「枝が一拍遅れた」)だけにする。数値はエリスのログに限り、トリガーの仕様は骨組みの裏設定に置く。博之の目で読む限り、読者は数えなくてよい。
- **成瀬の回りくどさ**: 武器を「博之の殺害予告テープ」一本にする。撤退握りつぶしとテープの二層を整理する。成瀬の目的は一行で言える形にする(「陽子を餌に博之を手駒にし、不要なら処分する」)。14話の編集と15話の録音は役割を分担する。
- **東雲の黒田排除**: 判断材料を博之自身の行動に置く。東雲が作戦室モニターで、暴走エリスが友軍47名を食うのを見る。そして一行、「あれは黒田の手しか離さん。離さんなら、そこに置いておけ」と言わせる。退避通告を黒田に伝えない理由もこれで通る。リールは補強に降格する。7話で「制御できるのは黒田一人」と匂わせておくとさらに筋が通る。
- **陽子喪失の分かりにくさ**: 因果が3つ欠けている。①誰が起動したか、②陽子はいつ試験場に着いたか、③消えた原因は何か。直しは、陽子が試験場に着いた一場面を足すこと(視点は三人称・陽子、15話の末か16話の頭)。そこで成瀬が試験を前倒しにする。読者が「成瀬が起動、陽子が巻き込まれた」と一文で言えるようにする。博之の目に残る「雪・靴・袖」はそのまま活かす。
- **新兵の死と斑鳩の構図**: 構図は既にほぼ出来ている(12話で震える、16話で書き換え、17話で研ぎ、死)。足りないのは新兵の肉付けと斑鳩の傷の可視化。
  - 三枝を3話と10話にも出し、博之に一度は礼か悪態を言わせる。
  - 囮を出した後、斑鳩は食事を残す。砥石に三枝の名を彫り、博之はそれを読んでしまう。
  - 17話で研ぐ時、斑鳩は三枝の名の上に親指を置く。
  - これで「傷ついて壊れて、最後に博之の武器を研いで死ぬ」が、舞台道具ではなく斑鳩自身の弧になる。
- **明け祭の規模感(要決定)**: 案を出す。
  - 場所: 第4監視棟の地下旧貯蔵庫。広さは約100畳。
  - 人数: 兵と職員が約40名。屋台は輪投げ、唐揚げ、射的の3台。時間は夕方から夜の2時間。
  - 集合写真: 写るのは12名と、くしゃみで半分切れたスメラギで、18話の「十二人/十三人」と整合する。
  - 入口で博之が「思ったより人がいる」と感じる一行で、規模を読者に渡す。
  - canon の勝浦新都市の明け祭とは別物の「ごっこ」だと明示する。
- **エリスが「博之が壊れないため」に除外する論理**: オーナーの案を採る。
  - 19話の願いを「博之が会いたい人」ではなく「博之が壊れない条件」に置き換える。
  - エリスは睡眠中の発話ログ(陽子412、斑鳩388、白石290、皇97)で気づく。博之は「自分を生かして死んだ者」に潰される。
  - 20話ログの「処理:実行 理由:入力なし」を「理由:マスター負荷閾値超過」に変える。
  - 陽子だけは「排除判定:実行不可」のまま。この差が、エリスが愛を覚えた証拠になる。
  - 斑鳩・白石の新世界での存在は canon 未決なので「要決定」。

## 5. 0部ラストについて

**永劫の長さ**: 約400日を提案する(要決定)。「1年と少し」は季節が巡るのに十分で、二人が数えられる長さでもある。苦難は3つ(対の嘔吐、ナイフ砕け、嘘の唐揚げ)で足りる。永劫の重さは日数ではなく「数え方が変わる」ことで出す。最初はエリスが数え、途中から博之がやめ、最後は二人とも数えなくなる。

**オーナー案(採る場合の形)**: 方向は良い。「報復」という題に直結する。ただし怒りの置き方に注意が要る。
- エリスが観測するのは世界全体ではなく、小さなもの1つにする。スメラギの家庭の一枚の写真、陽子がタッパーを詰める手など。ログに「観測」と書くだけで、博之には見せない(博之は寝ている)。
- 怒りは「ズルい」ではなく、「博之のいない世界が成立している」ことへの、数値化できない反応にする。幸福が博之を必要としていない事実に、エリスが反応する。
- リライトは破壊ではなく「差分の平準化」とする。ハッピーな世界を壊すのでなく、博之との境遇の差を埋める方向に使う。こうすればエリスの悪行が小さくなる。
- スメラギ生存はオーナー案と三嶋案(消去)が衝突する。要決定。私は「元の世界側では生きていて、新世界には存在しない」の両立案を推す。ただしエリスの動機が「怒り」になるぶんヘイトが上がるので、除外の理由を「博之を壊さないため」に置いて下げる。

**採らない場合の代案**: 元の世界を見せず、観測ログの該当欄を「(窓なし)」で終える。怒りは出ず、除外の論理だけが残る。これでも二部は成立する。

**二人の傷の量の目安**
- 傷は3つに限定する。①記憶の封鎖、②日常動作の欠落を1つずつ(エリスは箸が使えない、博之は味覚の一部)、③罪の秘密(エリスだけが全部覚えている)。
- 非対称にする。博之は「何かを失った感覚」だけを持ち、エリスは「全部覚えている罪」を持つ。
- 直接責任を負う死者は、二人合わせて1〜2名(スメラギ)まで。これ以上は二部で生きてくれなくなる。
- 学園コメディに入る条件は、傷が笑いの隙間から覗く程度に小さく、日常動作に出ること。命の重さには触れない。

## 6. 先の構想に向けて、0部で立てておくフラグ(最大3)

1. **泥と海の因子は敵でも味方でもない(星の意志の伏線)**: エリスのログに一行入れる。「因子:敵性/友性いずれの定義にも該当せず。環境」。星のバフにつながる。
2. **ヤマトは空間を貫通する(星間兵器の伏線)**: 18話の試作ヤマトが空間を裂くことを、「射程が空間に届く」と一語で匂わせる。冥王星まで届く兵器の下地になる。
3. **継承物の整理(子の世代)**: 砥石、袖で包んだ破片、献立ノート、ジャケットのうち、第1部で道場に残すものを決める。二人の子供が持つ物を、0部で最低2つ仕込む。

(1と2は、先の構想が canon に入るまで保留。canon の部の切り方と差があるので、オーナー確認が要る。)
