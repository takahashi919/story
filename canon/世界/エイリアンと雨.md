# エイリアンと雨

## 出現のルール（確定）

- エイリアンは地球上で、海水の成分がないと生きられない。だから**海水が染み込んだ雨の日に地上へ出てくる**（mtg/0 オーナー）。
- 合言葉：『雨の日、空から海水の匂いが降る時、奴らはやってくる』。
- 雨は潮の匂いがする。雨を吸って外殻の硬度が上がる。雨中の海水は、防人の放つ光の魔力を乱反射させて減衰させる（旧原稿 00c・03）。
- **呼び名（第0部）：「海魔（かいま）」**（確定。決定ログ 2026-10-12）。
  - この呼び名は、圧倒的に不利な戦況の中で生まれたプロパガンダ。「エイリアンはなんとか倒した。だが強い敵が現れた。引き続き頑張ろう」という筋書きで、**名前だけを変えて** 同じ敵と戦い続けている。
  - 戦況の悪さと、内陸と前線で情報源が共有されていないことを良いことに、内陸の富裕層向けに都合のいい改編や広報をして甘い蜜を吸っている者たちがいる。本編で描く（オーナー指示）。報道の付け替え（`世界/防人と軍.md`）や成瀬（`人物/その他の軍人.md`）と繋がる。
  - 前線の古参兵が「エイリアン」と呼ぶか「海魔」と呼ぶかで、世代や立場を書き分けられる（仮。演出案）。
  - 第1部（人類が押し返した世界）では改名の必要がないので「エイリアン」のまま（仮）。
- 第1部では予報局が天気予報と一緒に「エイリアン注意報」を出す。梅雨入り・梅雨明けが戦況の節目になる（`sources/01`）。
- 冥王星付近に母船。在来生物の遺伝子を組み込んだ適応型がいる。悪魔の王の部位に引き寄せられる。

## 天気は二つの世界で共通（確定。決定ログ 2026-10-12）

エリスの改変で変わったのは1961年の一事案であって、空ではない。
1980年に雨が降った日は、第0部でも第1部でも雨が降る。**同じ雨の日に、違う世界で、同じように奴らが来る。**


## 雨の日の台帳

襲来日は「雨の日」でなければならない。天気は **気象庁の勝浦の日別値**（`data/気象/`、1980〜1982年）で確かめる。

```
python3 harness/tools/weather.py 1980-05-04            その日の天気
python3 harness/tools/weather.py --rain 1980-06        その月の雨の日
```

「雨の日」の判定：天気概況（昼 06〜18時／夜 18〜翌06時）に「雨」を含む、または日降水量 1.0mm 以上。1980年は169日が該当する（5月18日、6月14日、7月18日、8月13日）。
