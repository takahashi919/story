# 決定を canon に書く

引数：$ARGUMENTS（決まった内容。なければ直前の会話からオーナーが決めたことを拾い、書く前に一覧を見せて確認する）

1. **どこに書くか決める**：`canon/README.md` の地図から、その事実が属するファイルを **一つだけ** 選ぶ。複数のファイルに関わる時は、主のファイルに書き、他からはリンクで参照する。同じ事実を二か所に書かない。
2. **衝突を確かめる**：その事実と食い違う記述が canon・`sources/`・各話の `骨組み.md` にないか Grep で探す。
   - canon と食い違う：古い記述を新しい決定で置き換え、決定ログに「〜を変更（旧：…）」と書く。
   - `sources/`・`archive/` と食い違う：原文は直さない。canon 側に「正史・旧資料からの変更」と注記する。
   - 書き終えた話の本文と食い違う：その話の `整合.md` に「要修正」として追記し、オーナーに伝える。
3. **書く**：確度（確定／仮／未決）と出典（`決定ログ 日付`）を添える。
4. **決定ログに1行**：`canon/決定ログ.md` の表の末尾に、日付・決定・反映先を追記する。未決リストから解消したものは消す（決定の行に「未決解消」と書く）。
5. **報告**：書いたファイルと、影響を受ける話をオーナーに伝える。

オーナーが「仮」「とりあえず」と言ったものは「仮」として書く。オーナーが決めていないことを確定として書かない。
