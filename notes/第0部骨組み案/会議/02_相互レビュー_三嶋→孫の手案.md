# 相互レビュー：三嶋与夢 → 孫の手案（パターン②）

> 読んだ範囲（本人申告）：設計書、全話のシーン構成、★シーン本文。ep14〜15 は構成と解説のみ、ep20〜21 は本文まで。4(c) の比較は、自分の案を読み直さずに孫の手案側の処理を見て判断。

いつも応援ありがとうございます。

## 1. 総評
- 骨格は強い。「全員の優しい嘘の利息が8/3に一括請求される」という一本の因果で、手負い残し→白石→全滅戦、「内緒」→失言→永劫、といった負債の順序が筋で通っている。
- 唐揚げ6個、ジャケット、缶の音という「物の時計」は、私の案にない部品。盗みたい。
- 弱点は第1幕(0〜8話)。「話数表どおり」に忠実なので、オーナーの「素案に寄せすぎ」はここを指している。毒も驚きも8話までは薄い。
- 8/3 に ep16〜18 を3話連続で積むため、後半は重い。ただし陽子喪失の状況は「路面が泥ごと剥がれる」と物理で書かれていて、私の案より明確に分かる。
- 永劫1万年は設計の核だが、オーナーが長すぎると言っている。ここは作り直しになる。

## 3. 捨てるには惜しい部品(トップ7)
1. **F1 待て/よし→待て破り(最終行)**: 躾の言葉を、愛の爆発ではなく生涯一度の不服従にする。全体の背骨になる。
2. **永劫の物の時計(F13・F3・F10)**: タッパー、擦り切れるジャケット、缶の音。説明なしで時間を見せられる。
3. **F21「美味い」の嘘**: ep9 で早すぎる「美味い」を置き、ep12 で露見し、ep20 でリライトの引き金にする。偽悪の二重構造が最後まで一本で通る。
4. **ep13 息継ぎの複製**: 看護師の職能だけで嘘を見抜く。陽子が見抜いた上で目を瞑る。「見ないふり」の完成形。
5. **ep12 斑鳩の缶(12枚+白石の札)と「お前が数えろ」**: 数える癖を意味のある行為に変える。「少し多い」という指摘も、これで質が変わる。
6. **ep19 同文の真偽反転**: 「陽子の反応は確認されています」を12日目は真、52日目は偽で使う。
7. **ep20「今です、マスター」(0.31秒)**: 数字だけで檻の逆転を見せる。ここが一番怖い。

## 4. オーナーの指摘への応答
**(a) 「素案に寄せすぎ、もっと自由に」を自由にして化ける所3つ**
1. **第1幕の圧縮と、陽子×エリスの二人きりの回の新設。** ep5 と ep8 の日常を統合し、ep6 を ep7 に吸収して9話を7話にする。空いた枠に、博之が営倉で不在の一日を入れる。読者だけが見る安心で、破局の落差を作る。
2. **斑鳩を「壊す」線を通す(オーナー提案の構図)。** ep4「研ぐな」→ ep12 の缶 → ep15 の囮と、震えは既にある。足すのは ep15 で、斑鳩が自分の鉄則を破って博之のナイフの欠けの周りを整える場面。ep4 の「周りを整えろ」の実演で、これが斑鳩の最後の授業になる。そのナイフが ep19 で軽く折れる。斑鳩が壊れて、最後に博之の武器を研いで死ぬ、がそのまま成立する。
3. **ep12 の白石の死を「意図と結果の乖離」にする。** 通信車を前に出せと命じたのは成瀬。博之は偽悪の癖で「俺が残したせいだ」と自責する。ヘイトは成瀬に溜まり、博之の自責は誤りのまま残る。F2 は「手負い残し」から「自責の誤作動」に変わり、毒が増す。

**(b) エリス×陽子の掛け合いを破局までの安心スポットにする配置**
- 現状は ep1(二度揚げ)、ep3、ep5、ep12(陽子の「嘘なんてつかないから平気」)に点在していて、ep9〜11 と ep13 以降で途切れている。
- **配置**: 三つの型を決める。①エリスの数値ボケと陽子の叱り、②陽子が人間語を教える辞書ネタ、③博之が不在の二人だけの場面。①は ep1・3、②は ep5・9、③は ep10 帰還後と ep14 に置く。
- **強化**: ep10〜11 の重い連続の直後に③を入れ、ep15 のドア越しで一番笑えるネタを置く。笑った直後に ep16 で落とす。
- **回収**: 掛け合いの語彙を永劫で再利用する。「非効率なのが美味しい」「塩分は規定量です」は既に使われている。ここにエリスが陽子口調で「走るな、転ぶでしょ」を言う一行を加えれば、掛け合いが痛みに反転する。

**(c) 三嶋案へのオーナー指摘への反省と、孫の手案との比較**
- **数える癖の頻度**: 孫の手案は ep3 で数え、ep12 の「お前が数えろ」で意味を持たせ、ep13 で声に出して数える。少ない上に、主題と結びついている。孫の手案が上。
- **粒の4つ目トリガー**: 孫の手案は【 】のログ表示が主で、博之の目に数を意識させない。孫の手案が上。
- **成瀬の回りくどさ**: 孫の手案は几帳面さをカミソリ、ミラーの角度、万年筆という物で見せる。私怨の根は意図的に空白。孫の手案が上。ただし ep13 は三人称過多。
- **東雲の黒田排除の判断材料**: 孫の手案は「友軍に撃った、補佐官の独断の書類、一度しか撃てない試作、同一線上」と材料を積んでいる。孫の手案が上。
- **陽子喪失の分かりにくさ**: 孫の手案は荷台の縁、剥がれる路面、タッパーの熱で分かる。孫の手案が上。
- **新兵が舞台道具になる問題**: 孫の手案は ep6・7・10・12 で白石を継続して出す。ただし斑鳩の「壊れて研いで死ぬ」構図は未実装で、これは私の課題。
- **明け祭の規模感**: 孫の手案は地下の第4監視棟、ごく少人数、屋内、7/28 と明示する。孫の手案の形を土台にしてよい。
- オーナーの除外案(エリスが、博之が壊れるのを恐れてスメラギ・白石・斑鳩を除外する)は、孫の手案の ep21 で理由欄が空白になる処理とそのまま噛み合う。空白の前に「【対象:マスター　崩壊確率 ■■%】」を一行置けば、読者は動機に気づける。

## 5. 0部ラストについて(三嶋案)
**オーナー案の評価: 採る。ただし3点を直す。** エリスの怒りが「博之のため」から「他人の幸せの破壊」に滑る形は、毒として理想的。怒りが読者の代弁にもなるので、ヘイトが解放に反転する。
1. **永劫を短くする。** 1万年をやめ、約10〜30年にする(要決定)。唐揚げ6個の節目は、日数ベースで組み直す。
2. **裏世界の観測は「窓」を一度だけ使い、エリスのログだけで見せる。** 例:【観測座標:勝浦　侵略個体:ほぼ0】【皇征弦:生存　家庭:あり】。博之には見せない。
3. **怒りの引き金を二つ重ねる。** 窓の食卓の「本物の美味い」と、博之の血の味の「美味い」の嘘。孫の手の引き金をそのまま残せる。

**二重構造**: 博之は陽子のために飛び込んだだけで、結果は世界を救っている。誰も知らない。読者が一番痛い所を、エリスの怒りが先に叫ぶ形になる。

**代案**: 窓の中に陽子も生きて映す。ep19 の「陽子は生きています」という嘘が、別の枝で真になる。その幸せを上書きするのがリライト。ただしオーナーの案より毒が強いので、虐めすぎの懸念が増す(要決定)。

**傷の量の目安**
- **原則**: 傷は「原因を説明できない癖1〜2個」に畳む。日常は壊さず、週に一度顔に出る大きさ。
- **博之**: 身体痕(歯形・胸の傷)と、理由のない喪失感。陽子の死は知らないまま。
- **エリス**: 「本機の記録削除」を部分的な失敗にして、「何をしたか不明の罪悪感」だけ残す。完全削除だと二人の傷が揃わず、オーナー案の「二人が傷を負う」に反する。
- **回避策**: 永劫を短くする、博之は絶望の底を見ないまま眠り際に終える、陽子の死は二部開始まで保留する。これで二部で生きてくれる余地が残る。

## 6. 先の構想に向けて第0部で立てておくフラグ(最大3つ)
(canon の部の切り方と、オーナーの構想は食い違う。要確認。)
1. **ヤマトは「星から借りて撃つ」の布石。** ep18 の試作砲撃の直後、砲台の周りだけ草木が枯れる、潮が引く、といった痕跡を一行置く。母艦ごと滅却する最終兵器の仕組みの種になる。
2. **母艦の兆候。** ep14 のラジオ「巨大反応」を、地上ではなく軌道上と読める一語にする(冥王星付近の母艦への接続)。
3. **傷を「癖」として一部・二部に持ち越す。** 博之の数える癖と、エリスの袖をつまむ癖。二部で子供が真似をする、という学園コメディの笑いと切なさの土台になる。

反省点は色々とありますが、孫の手案の後半は、素直に盗む価値があります。
